## B. 六个待决主题（按门禁归属展开）

### B-01 Lmin 安全最终策略 → G-01（P0，仅 Lmin 开放前阻断）

- 现状：工程无 `Lmin` 概念，`SpawnModifiers` 无保底/回退路径（`MonsterSpawning.cs` 全文无保底逻辑）。
- 风险：M3 代理模型已给出 `[4,4]` 零击杀/零 XP 反例；一旦开放 Lmin 而队伍强度不足，将出现不可恢复的 0 收入死锁。
- 待裁决：① 是否禁止 `[Lmax,Lmax]`；② 是否强制 `Lmin ≤ Lmax-1`；③ 是否引入保底最低收益/紧急回退；④ 未过验收前 Lmin 购买是否对真实玩家隐藏。
- 执行侧承诺：接口可承载任一方案（区间购买、逐一英雄准入校验、恢复钩子、风控监测点），**不做策略决定**。

### B-02 城堡准入证明 → G-02（仅城堡规格定稿前阻断）

- 现状：城堡无固定等级，走全局链。
- 待裁决：`Lmax >= n` 即可，还是需要"已击杀等级 ≥ n 的怪物"事实记录。
- 影响：若需事实，则要在 `Run` 层新增击杀档位账本（与 KP 账本同源）。
- Review 意见：推荐 `Lmax≥N`，避免新增隐性门槛。

### B-03 AR/DR 曲线与倍率 → G-03（仅挡正式数值）

- 现状：AR/DR 不存在；V1.2 明确 `Clamp((AR/DR)^1.5, 0.40, 1.50)` 是示例。
- 已放行部分：用户已同意临时试用 **40%–150%**；P2-4 实现"可配置倍率 + 确定性成长接口"，用可复现示例测试。
- 仍待定：每职业每级 AR/DR 成长形状、倍率函数最终形式、暴击"评级惩罚/少数天赋恢复到 100%"的具体口径。

### B-04 公共 XP 成本曲线 → G-04（仅挡正式数值）

- 现状：`herolevel.csv` 是 1 万行累计 ATK/HP 表；经验成本与怪物 XP 仍按旧个人经验口径。
- 待定：升级成本增长形状、怪物 XP 增长形状、天赋点总供给是否随曲线调整。
- 已确认不需再裁决：**无等级差衰减、当前无池上限**。

### B-05 装备/卷轴/药剂最小口径（不入门禁表，属 M5 范围确认）

- 现状：三者均不存在，`item.csv` 仅 4 行杂物/货币。
- M5 需确认的"交互雏形范围"：装备先选**代表部位组**（6–8 中取子集），卷轴**至少 1 种**基础攻击，药剂**至少 1 种**有效持续 Buff；但**5 槽机制、库存/掉落/保留/到期必须真实生效**，不能缩成技术演示。
- **阈值口径修正（Review）**：批量一键换装按"可替换的**部位件数 ≥ 5**"触发，不是"≥5 名英雄"。

### B-06 成就点经济与第 5 席售价 → 不入编码门禁（详细经济后置）

- 现状：无任何成就体系；`hero_unlocks` 是轮内击杀门槛。
- 本轮必须做：`Account/Run` 分层、有效重生/放弃接口与持久化。
- 后置到正式经济设计阶段：成就点计量与防刷、商店清单定价、第 5 席昂贵价格。
- 仍建议在 M5 确认：至少两次符合规定的轮次通关资格判定口径（影响 `Account` 事实集设计）。
