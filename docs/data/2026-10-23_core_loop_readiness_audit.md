## 01｜总览

**真实可用（有代码路径 + 配置 + 检查）**

- 五职业角色、等级成长（经验表 10000 级）、自动战斗、地牢/世界自动冒险、失败复活与重试。
- 天赋树（61 节点、39 主动/22 被动、16 个绑定正式技能）、主动技能槽 1→5。
- 星图（17 节点）：全队攻击/生命、队伍扩编、主动技能槽、洗点与洗点折扣，全部真实扣金币并写入存档。
- 技能 BD：光环、诅咒、召唤、连锁、尸爆、旋风/脉冲、Proc 限次均已接入战斗。
- 五章怪物身份与投放池、Boss 技能包、4 类精英词缀（本轮之前已交付）。

**主要缺失环节**

1. **中期金币消耗几乎只有星图**：星图满级总计 **1463 金币**，之后没有其他金币用途（装备/商店/赌博/雇佣兵均未开放），金币会成为无消耗资源。
2. **难度跳跃过大**：第一章挑战等级普通 1–12、噩梦 44–49、地狱 73–78；中间没有过渡层，跨难度相当于等级 +32/+30。
3. **等级上限事实上是 10000**（`HeroLevels.Count`），没有阶段上限或软上限设计。
4. **装备/Loot 系统未开发**：掉落只有 `gold` 与三种杂物（自动出售），没有装备、词缀、鉴定。
5. **长时间挂机与收益曲线没有实测数据**：本轮未能运行经济模拟（原因见 05）。

**能否形成最小闭环**：能形成「战斗→经验→升级→属性/天赋/技能→更强→更高难度」的**战斗成长闭环**；但「金币→星图→能力」这条链在星图满级后断开，且缺少装备层，长期目标不足。**判定：最小闭环可运行，但约在星图满级后失去持续成长动力。**

**最严重的 5 个阻断问题**

| # | 问题 | 证据 |
|---|---|---|
| 1 | 金币后期无消耗 | `star/star.csv` 17 节点合计 1463 金；`village/town_npc.csv` 商店/赌博/雇佣兵均“待开放” |
| 2 | 难度断层（12→44→73） | `chapters/act1/dungeon/poi_challenge.csv` 三档 challenge 范围 |

## 03｜系统流转与断点

### B01 经验 → 英雄成长（**已完全接通**）

`怪物死亡`（`SkillRuntime.cs:136`）→ `GainMonsterExperience(target.RewardXp, target.Level)` → 每名上阵英雄按等级差百分比结算（`HeroExperience.cs:34`）→ `GrantHeroExperience` 扣经验并升级 → `MaxHp/Attack` 按表差值增加 → 立即参与战斗与容量计算。

- 经验基数 `XpBase=2 × 怪物等级 ×（Boss?4:1）`（`monster/monsterlevel.csv` + `SpawnRule`）。
- 等级差倍率 `experience_level_rate.csv`：同级 100%，落后 5 级 300%，等级越高收益递减，超出边界沿用首末行（可低至 0%）。
- 倒地英雄同样获得经验（`HeroExperience.cs:34` 注释与实现）。

### B02 金币 → 星图（**部分接通：产出连续，消耗有终点**）

`击杀`→`RollDrops`（金币概率 1.0，数量 1–3，×价值倍率 `1+0.25×(L−1)`，Boss ×4）→ 房间战利品 → 清房后走近拾取入账（`GameSession.CollectLoot`）→ `Stars.Purchase` 扣金币 → `ApplyStarTotals` 更新全队攻击/生命或解锁槽位 → 参与战斗属性。

- **断点**：星图满级后金币无任何用途；三档难度金币收入提升，但没有对应的高阶消耗。
- 洗点消耗同样计入金币，但受星图节点门控。

### B03 技能天赋 → BD（**已接通，覆盖面不均**）

`升级得点` → `Talents` 学习/升级（行门槛 5 点）→ 绑定节点走 `talent.csv.skill_id` → `SkillRuntime.Commit` 按 `skill.csv` 执行；未绑定节点走 `CastTalent` 旧分派。

五职业各一例：

| 职业 | 可用例子 | 行为变化 |
|---|---|---|
| 野蛮人 | `barb_bash` 绑定 `猛击` | 近战主动，CD 60 tick，前摇/恢复 3/3 |
| 圣骑士 | `pal_prayer` 光环 | 团队持续治疗/增益，占一个槽 |
| 法师 | `mage_fireball` + `sor_chain_lightning` | 单体弹道 + 有界连锁 |
| 死灵 | `nec_raise_skeleton` + `nec_lower_resist` | 召唤上限 3（每只容量 1）+ 诅咒减抗 |
| 游侠 | `ran_multishot` + `ran_guided_arrow` | 扇形多箭（同次可命中同目标）+ 导引弹 |

不足：游侠只有弓系；死灵白骨/毒素分支部分节点仍是旧 `CastTalent` 行为；无装备层，BD 只能靠天赋+技能组合。

### B04 难度 → 收益（**接通，但跳跃与收益结构有风险**）

- 难度只改 `poi_challenge` 与 `floor_plan` 的怪物等级/预算，不改公式。
- 第一章：普通 1–12、噩梦 44–49、地狱 73–78。
- 怪物强度：HP ×`1+0.18×(L−1)`、攻击 ×`1+0.12×(L−1)`（`monster/monsterlevel.csv` 线性）。
- 收益：经验 ×等级×等级差倍率；金币 ×`1+0.25×(L−1)`；Boss 经验/金币 ×4。
- **风险**：跨难度是 +32/+29 级的硬跳；玩家若等级不足，等级差倍率会让经验变成 0%，形成“打不过也练不动”的死点。当前靠“重复挂机 + 回城换难度”缓解，但没有中间档。

### B05 长时间挂机（**可运行，未实测**）

自动链：旅行 → 选普通地牢 → 自动战斗 → 清房拾取 → 下一房/下一层 → 通关 → 回村交易 → 下一目标；城堡与支线必须人工发起；全灭在当前区域村庄复活并计入重试。

断点候选：①星图满级后金币无用途；②难度断层导致“刷低级无收益、打高级打不过”；③天赋/星图需手动操作，离开管理界面不自动消费资源（不是错误，但会积累未使用资源）。

### C05 资源收支（配置推算，不是实测）

## 08｜下一阶段开发建议（只基于审计事实）

**最小闭环所需工作项（按依赖排序）**

1. **经济实测入口**（前置）：离线经济模拟器（只读、输出 CSV），用于确认 30min/2h 收益曲线与卡点；否则后续调参没有依据。
2. **中期金币消耗**：星图满级后的消耗点（不必是装备）。最小方案：扩展现有星图/天赋的持续消耗（如洗点、重置、额外栏位），或开放城镇已有的“售卖/赌博”雏形。
3. **难度过渡带**：在 12 与 44 之间、49 与 73 之间补 1–2 个可选挑战层，或让噩梦入口按角色等级动态降档，避免“打不过也练不动”。
