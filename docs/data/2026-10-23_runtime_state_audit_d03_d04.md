# 运行现状数据：D03 入场/站位 与 D04 怪物/技能AI

2026-10-23。专项统计文件：汇总当前版本**已实现、可验证、不可测量**的项，供后续 AI、站位、镜头与房间规格开发参考。数据来自代码与确定性 Core 检查，**不是实机长时间采样**。

## D03 入场与站位

### 已有参数（全部来自配置，非硬编码）

| 参数 | 值 | 作用 |
|---|---|---|
| `combat_entry_pass_depth_milli` | 1500（1.5U） | 通行边界：无近距威胁时必须自然入房该深度才允许停下攻击 |
| `combat_entry_threat_range_milli` | 1200（1.2U） | 入口浅区近距离威胁：可提前接战 |
| `combat_entry_delay_milli` / `alert_cap_milli` | 800 / 2000 | 敌方基础警觉 / 兜底上限 |
| `combat_entry_melee_depth_milli` | 2800（2.8U） | 近战展开纵深（通行之后的推进目标，不强制） |
| `combat_entry_ranged_depth_milli` | 900（0.9U） | 远程展开纵深 |
| `combat_entry_melee_spread_milli` / `ranged_spread_milli` | 1100 / 450 | 横向间距 |
| 刷怪留白 | 四边 0.8U + 入口内侧 1.5U | 出生避让（32 次有界重试） |

### 已验证（`--room-entry-checks`，确定性 Core）

- 四方向入口 × 6×5 / 7×6 / 8×7 / 9×8：逐单位通行独立，队首接战不放行队尾。
- 近距提前接战（1.2U）与“施法/来袭弹道/被锁定”同样可提前接战，接战后不补做通行。
- 远程在通行边界即可停下攻击，不会继续深入。
- 敌方警觉：0.8s 基础无条件保留；之后按前方通行进度或近距遭遇提前启动，最迟 2.0s 兜底。
- 出生避让与四边留白，且同 seed 可复现；怪物数量不因避让改变。
