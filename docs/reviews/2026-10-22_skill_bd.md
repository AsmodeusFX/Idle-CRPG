## 一、G0 阶段结论

- 能力审计：确认工程为二维 20Hz 固定步、单一 `SkillRuntime` 动作权威、`DamagePipeline` 唯一伤害入口；G01～G06（多光环、多诅咒、召唤归属、击杀连锁等）原则可用，但存在运行缺口，须按切片补。
- 冲突与迁移：包内 X01～X10 与现实差异集中在“新旧防御公式、四要素聚合、四人/免费点数假设、直接复用旧 ID”。结论是一律不默认批准，逐项报批。
- 审批请求 P1～P4：公式修改方向批准但参数待定；保留现有 5 人/初始扣点/NPC 换队规则；新技能另做迁移方案、旧数据归档为测试数据；先合并文档再动代码。
- 用户最终裁决：同意修改公式并给出原型参数；“保留我们已有设定”；新技能独立迁移；随后明确“开始执行”，并批准 A 阶段“同次施法多箭可命中同一目标，仅隔离 QA”。

## 二、执行内容

| 范围 | 变更与边界 |
|---|---|
| 统一公式 | 物理护甲 `K(L)=5+(L−1)`（L 为攻击者等级）、四元素抗性截断 −100%～75%、取消最低 1 点保底、威能与易伤同池加算；`DamagePortion` 分类型后共享命中/暴击/格挡事实求和，仍只有 `SettleDamage` 应用一次 HP 与奖励 |
| 配置 | 新增 `combat/armor_curve.csv`；`damage_rule` 明确暴击与抗性截断，删除旧最低伤害键；`damage_multiplier` 改为 `power_damage_pct`；同步字段字典与校验 |
| 快照兼容 | `CombatVersion=2` 把旧倍率 x→x−1，一次性且幂等；出手攻击/等级随投射物与待命中 Work 保存 |
| A 弹道 | 泛用 `SpawnProjectile` 支持 CSV 弹数与扇形角；每箭按二维线段扫掠、各自去重，允许同次多箭打同一目标；`OriginCast` 贯穿普攻/技能/飞行/派生效果 |
| B1 光环与诅咒 | 复用唯一 Buff 来源与分组；多光环择强与离开回退、周期治疗不复活、跨房激活、分类型易伤/减抗、Forced 安全边界、防御新星、导引箭有限重选 |
| B2 独立召唤 | 新增 `skill/summon.csv` 与 `Summon` Effect；召唤物为独立 Actor，排在英雄与当前房怪物之后共用战斗 ID，不并入 `Heroes`；属性按主人施法时基础值比例继承；上限 1；跨房保留实际 HP；死亡不产尸/奖励，击杀经验归全队；主人死亡/卸槽/换队/全灭撤销 |
| C1 有界链 | 新增 `skill/chain.csv` 与 `Chain` Effect：链根为目标选择结果，逐跳到最近未命中敌人，受跳距与总目标上限约束，按 `damage_decay` 衰减，每跳走唯一 `SettleDamage` 并继承 `OriginCast` |
| C2 尸体与尸爆 | 本房 `CorpseState` token，每次怪物真实死亡登记一条；`CorpseExplosion` 原子移除 token 后走唯一伤害路径，同尸体竞争只有一次生效；无尸体跳过且不进冷却；快速内存快照保留、正式检查点清空；女武神复用召唤运行时 |
| C3 旋风与 Proc 限次 | 新增 `AreaPulse` 与 `skill/proc_limit.csv`：脉冲每拍以当前目标位置为圆心；Proc 限次按（根源施法, 触发, 目标）计数，支持每 Cast / 每目标上限，`direct` 过滤阻断递归；不改变旧天赋旋风行为 |
| QA 隔离 | 各切片夹具 ID 只在 TEST_ONLY 夹具注入，正式 `Config` 重载不出现；未修改玩家已学/已装备内容 |
