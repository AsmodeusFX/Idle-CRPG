## 二、战斗、技能、属性与等级迁移

来源 `Idle-Diablo`，只读参考。迁移是适配现有架构，不是整套换引擎：`DamageCalculator→DamagePipeline`、`SkillRuntime/Effect/Buff→SkillRuntime+SkillBattleState`、`AbilityRuntime→二维 AbilityRuntime`、`SkillTables→SkillConfiguration`。

| 议题 | 结论 |
|---|---|
| 三阶段伤害 | 保留 DMG1/2/3；DMG1 改为 `max(1, 攻击−护甲)` |
| 事件顺序 | 闪避→格挡→暴击；格挡与暴击可同时成立；基础暴击 1.5 放 CSV |
| 五池 | 技能加算、通用加算、独立暴击加算、独立倍率叠乘、同 Debuff 加算/不同 Debuff 叠乘 |
| 技能加值 | 300%+30%=330%（加算），不是 390% |
| 精度 | 沿用项目浮点，不复制源 Demo 取整 |
| 时空 | 源一维/8Hz → 二维/20Hz；作用域限当前房间；像素 100:1 |
| 成长 | 英雄每级 ATK+4、HP+18 但改累计等级表差值；怪物线性 HP+18%/级、ATK+12%/级，护甲不随级涨 |
| 上限 | 英雄/怪物分别取等级表尾（原型覆盖 1～10000） |
