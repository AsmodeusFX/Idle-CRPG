- 六装备槽，一件一种主属性ATK或HP，按HeroInstanceId掉落与穿戴；跨ATK/HP候选必须由玩家判断，不允许出售保护候选。英雄页“穿戴更好装备”与右侧`>4`项目合批是**两个**入口。

- 装备/耗材等级与掉率以被实际合法击杀怪物的`MonsterOrigin.ActualLevel`产生，非章号、POI旧级、当前Lmax统一赋值；相应金币/XP/KP奖励都走已有账本。

## 3. 必须拆开的三个层次

**身份映射**：S11 `RARE → uncommon`、`EPIC → rare`是清晰的四阶**转换提案[P]**，保留设计源ID追踪；显示名采用用户已确认的生产名。按品质重命名或换ID前必须覆盖`EquipmentSave.Quality`旧档；如对老物品价值有实质影响，保留H参数并走产品数值裁决。

**经济参数**：`S11_31级...`概率按`0..1`小数记录，`S12_31怪级...`概率按`0..100`百分数记录；单位不能混用，避免100倍差异。S11 25座主线城堡“首通额外1件装备”仍是[P]**未批准奖励**，C2-B只应做试验开关/报告，不直接面向玩家发放。

**真实Effect**：SC01–04以已有最近合法敌方目标为入口；SC05建议[P]在合法战斗中一键保护己方，不把保护卷轴伪装成敌方伤害卷轴；SC02最多3名不同目标；SC03一次性范围伤害（不是新增持续地面伤害）；SC04减速来源随时效正常撤除；SC05真正保护已配置的队伍承伤（目标建议[P]为己方队伍，非最近敌人）；PO02临时MaxHP变化的当前HP语义必须沿既有HP装备技术边界仔细确定，不得凭空“治疗”；PO03只对生效期间合法击杀基础金币加成、不加装备售出或离线；PO04只加真实非战斗移动，不改战斗Tick或地牢内容速度权威。
