## 1. 原版 D2 记忆点与这次改造的边界

原典强记忆点：鲁·高因、碎石荒地/石制古墓、干燥高地/死亡之殿、遥远绿洲/蛆虫巢穴、遗失城市/古代通道、群蛇峡谷/利爪蝮蛇神殿、皇宫/后宫/地窖/神秘庇护所/召唤者、术士峡谷/七座塔·拉夏古墓/都瑞尔、鲁·高因下水道/拉达门特。

- **不照抄地理**：原版神秘庇护所从鲁·高因皇宫内部进入；本图将皇宫绘为城南区域，Gate 从城南开启，绝不把它错误地放成“群蛇峡谷的后继地面区”。
- **保留魔法传送**：真正进入术士峡谷的通路是神秘庇护所传送门 `ARCANE_PORTAL`；群蛇峡谷提供必需剧情前置，不从蛇谷物理道路直通峡谷。
- **七墓总数**：六座假墓地牢 + 一个真墓终局 Castle，总计七座。为符合“本区必清地牢完成才能攻 Castle”的统一规则，六座假墓在本方案中设为必清，此处**与 D2 原版只需辨认正确墓穴的体验存在有意识差异**。
- **支线领域化**：原版鲁·高因下水道、古代通道属于地下城；为匹配每区域有 Castle 的项目结构，本版分别将**城边排水区**与**古遗迹周边**扩展为大地图支线区域。二者及其额外地牢属于改造，不是原典的独立大区域。
- **部分新地牢为占位内容**，名字和怪物/Boss 尚未批准；必要时可在保持地图和数量基础上换成 D2 风格的自有世界观命名。

### 3.1 两条主线分岔如何进入

`REGION_04` Castle 征服后，系统同步派生 `REGION_05` 和 `REGION_06` 已解锁。小队按已批准的 **全局最低 DungeonChallengeLevel → 同级主线优先 → AutoOrder / PoiId** 规则自动选择下一目标。Region 06 从鲁·高因皇宫南门进，不从 Region 05 绕行。

`REGION_07` 需要两条主线 Castle 都正式征服；经过 `REGION_06` 末端的神秘庇护所门 `ARCANE_PORTAL` 前往术士峡谷。地图演示不会显示在地面徒步前往峡谷的替代捷径。

### 3.2 两条支线

- **REGION_08 鲁·高因下水道**：本章起点即可发现，但 `SideRegionAuthorized=false` 时候选全排除；批准后，入口将纳入全局等级优先队列。
- **REGION_09 古代通道**：Region 04 Castle 征服后被发现；未经玩家批准不得进入。
- **支线 Castle**：进入支线不等于批准该支线 Castle；同样需要本区地牢必清 + Castle 独立人工批准。
- **回访**：即使都瑞尔完成、已进入后继章节，两个支线的已发现/已批准/通关状态仍按 `DifficultyId + ChapterId` 保存，玩家可以回来继续，不阻塞主线或难度解锁。

## 4. 三难度章节等级（沿用已批准的 V0.2）

| 难度 | 怪物挑战等级区间 | 推荐玩家等级区间 |
|---|---:|---:|
| 普通 | **13–20** | **12–21** |
| 噩梦 | **50–55** | **49–56** |
| 地狱 | **79–83** | **78–84** |

这些是**项目策划曲线**，不是 D2 原版的逐区域精确等级；D2 地狱难度古代通道等地区具有异常高区域等级的刷宝意义，本项目若之后需要模拟“高等级特殊地牢”，应新增显式 `SpecialLootLevel` / `MonsterLevelOverride` 方案，不要在首版偷偷突破已批准的章节挑战范围。

**全章节内独立 DungeonChallengeLevel** 是自动排序标签，并不强制等于首层怪物等级；推荐玩家等级是提示，不是解锁门槛；Castle 最后 Boss 可通过 Boss 特性/倍率控制难度。

## 6. 地牢每层格数、怪物数量与击杀建模

**定义**：大地图 Tile ≠ 地牢 DungeonCell ≠ 战斗系统内部位置/寻路细分格。一个 POI 入口可包含多层 DungeonFloor；每层在随机种子下生成若干连通的有效格，并满足布局类型与怪物预算。

每层格子预算强校验：

`ActiveCellTarget = EntryCell + CorridorCell + CombatCell + EliteCell + EventCell + ExitCell + BossArenaCell`

目标击杀量（样例公式，需实测）：

`PlannedKillTarget = CombatCell × CombatMonstersPerCellTarget + EliteCell × EliteGroupMonsterTarget + BossActorCount + BossEscortTarget`

| 难度 | 每普通战斗格目标怪量 | 每精英格目标怪量 | 单 Boss 场地 |
|---|---:|---:|---|
| 普通 | 3 | 3（精英1+随从2） | 1 Boss + 2 随从（候选） |
| 噩梦 | 4 | 4（精英1+随从3） | 同上（候选） |
| 地狱 | 5 | 5（精英1+随从4） | 同上（候选） |

**不等于实机击杀**：游走刷新、召唤、额外精英波次、未全部清图都会让实际数量偏离预算；这些应进入独立事件/实际 KillFact 统计。Boss 场地虽可占多个有效格，但仅按编队次数生成一个 Boss。

### 6.3 Boss Arena 特殊要求

- `R05-C01` 利爪蝮蛇神殿：固定 Boss 场地，Boss 后提交剧情任务物品；不能在大地图战斗。

## 9. 全自动攻略/人工批准的执行语义

1. 可用候选：已解锁区域 → 主线自动允许 / 支线必须已批准 → 大地图 Gate 可达 → 地牢未首通；Castle 另需本区所有必清地牢已完成且 `CastleApproved`。
2. 稳定排序：`(DungeonChallengeLevel, IsOptionalRegion ? 1 : 0, AutoOrder, ChapterOrder, RegionOrder, PoiId)` 升序。Castle 人工批准只让它进入候选队列，**不会无视排序立即抢占**。
3. 一个 POI 多层：从第一层开始随机生成，成功完成规定层与最终遭遇后写入该 POI FirstClear；不把 Castle 的内部层算作 Castle 自己的前置地牢。
4. Region 主线 Castle 征服后解锁一个或多个下游 Region。支线 Castle 不应解锁或阻断主线必需节点（如未来特殊奖励可以独立加）。
5. **跨章节返回支线**：保存进度、批准与章节通关事实均按难度独立持久化，前往新章不清理旧章未完成支线。返回后自动攻略仍先经过人工授权过滤。
6. Castle 批准有效期、失败回刷 CD/阈值、未完成 Dungeon 楼层断点、用户撤销批准权限等仍为后续体验细节；本 HTML 模拟采用已批准持续有效直到征服的工作假设，不假装它已进入 Godot。
7. 具体小队人数仍为 3–5 人的候选范围；Boss 场地按最大 5 人预留，但实际战斗空间是否足够仍须 Godot 实机检验。
