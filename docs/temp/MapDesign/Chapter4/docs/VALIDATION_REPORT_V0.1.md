# Chapter 4 V0.1 静态与浏览器测试报告

> 测试对象：本 ZIP 中 ACT04 配置、HTML 原型；**未导入或运行用户 Godot 工程**。

## 数据静态验证（通过）

- 7×7 共 49 格：1 格安全主城、28 格五区域、20 个 x 不可通行。
- 五个区域均独立 4 邻接连通；区域面积 5/5/6/7/5；每区 1 Castle。
- 19 个 Dungeon + 5 Castle = 24 POI。24 组全局坐标互不重复，且与区域字形吻合。
- 5 个跨区 Gate：1 主城入口、3 段主线、1 段需人工批准的地狱熔炉支线。
- 77 个独立 Floor / Castle Phase，在 Normal / Nightmare / Hell 三种难度共 231 条 Floor 配置记录。
- Floor 有效格分类加总一致；布局包围盒格数 >= 有效格数；每层击杀公式一致。
- 混沌避难所六阶段存在 **5 处封印事件、3 位固定封印守卫、1 位最终 Diablo Boss**（每难度）；固定演员不得由普通怪物池再次重复生成。
- 三难度离线自动攻略模拟：不批准任何 Castle 时停在区域 1 的 Castle 门口；逐座批准 Castle 后成功完成主线 20 POI；不批准可选支线时侧线 4 POI 均未触碰；主线完成后单独批准支线及支线 Castle，最终完整完成全部 24 POI。
- 支线不用作为主线最终 Castle 前置，支线可以在主线之后补清；同章节三难度保留不同进度实例。

## Chromium 浏览器交互检查（通过）

- 7×7 地块、Castle / Dungeon 标记、三难度详情能够渲染，**无 JS 运行时错误**。
- 点击「连续推进至下一批准点」首次完成三个 Dungeon 后停在区域 1 Castle。
- 点击相应区域的人工批准按钮，四座主线 Castle 分别进入候选并逐段完成。
- 未授权地狱熔炉不会进入自动挑战；主线完成后可以再开启地狱熔炉、批准其 Castle 并清完。
- 切换到地狱难度后进度独立且三难度等级显示正确；地图画布及关口可见。
