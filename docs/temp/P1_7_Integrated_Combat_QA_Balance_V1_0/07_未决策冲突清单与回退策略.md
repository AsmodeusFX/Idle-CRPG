## 防垃圾代码专项

1. 不新增第二套统计“权威状态”模块，不让遥测落回Core计算路径决定真实战斗结算。
2. 测试Profile与生产Profile严格隔离，TEST_ONLY不得进入正式装备/敌池/掉落/存档。
3. 不并存减法护甲和百分比护甲的未批准运行开关，除非明确用于经审批的迁移对照且在完成后清理。
4. 不新增独立BuffStacker/ProcResolver/CorpseManager/SummonController来绕过已有Skill/Effect/Buff/Trigger体系。
5. 新旧字段/枚举/配置清理需列明引用和回滚策略，不能只注释旧实现。
6. 每次切片交付代码搜索和差异说明，证明不存在无效双重真实来源。
