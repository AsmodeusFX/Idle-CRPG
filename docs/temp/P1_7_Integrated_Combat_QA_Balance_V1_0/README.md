## 交接文件性质

- `CONFIRMED`：用户已批准的行为合同，Claude审计已有工程后遵守。
- `PROPOSAL`：调平实验方案，只用于对照与审批；不可视为最终数值。
- `TEST_ONLY`：隔离测试夹具，**禁止自动合入生产数据、保存或掉落表**。
- `TBD`：待用户决定，涉及到的生产测试用例必须 `BLOCKED`，不允许随意补默认值。
- `UNKNOWN`：尚未获得真实工程证据。文档已交不等于 Godot 实现成功。
