# 05｜分层覆盖矩阵：职业 × 房间 × 章节 × 三难度

## 1. 优先低成本Smoke，后运行组合矩阵

第一轮**Small Smoke**：5职业单人1槽在TEST_ONLY简单房，4类基础队伍分别在T01、T04、T05、T08跑固定Seed，验证配置与战斗合法性。

第二轮**System Integration**：队伍 Q1–Q5 × 实验房 T01–T08 × 3难度 = **120个计划样本**（`data/scenario_matrix_TEST_ONLY.csv`，实际执行需队伍合法且相应难度映射已存在）。全体规划≠当前已可运行；上游缺失则记录BLOCKED。

第三轮**World Smoke**：Act1–5×Normal/Nightmare/Hell = **15个章节抽样计划**，选择用户真实POI/关卡快照与合法角色成长档，包含Boss锚点对照；不能从TEST_ONLY T01–T08推断五章体验已经通过。

第四轮**Special**：混沌五封印/三守卫、远古三人、巴尔五波、单Boss无尸体、满箱仓、跨房召唤、回城换人返回原房间、SaveExitLoad、退让贴边、四人五槽等。

第五轮**Long Idle**：Mini 480×240、多房间稳定挂机、重试与奖励，记录真实经过时间和有效逻辑Tick。阶段时长应由用户根据电脑和目标审批，不伪造1小时/24小时证据。

## 2. 队伍模板（仅测试）

| ID | 阵容 | 必须遵守 |
|---|---|---|
| Q1 | 野蛮人+圣骑士+法师+游侠 | 4名首发允许上阵 |
| Q2 | 野蛮人+法师+死灵+游侠 | 召唤前排 |
| Q3 | 圣骑士+法师+死灵+游侠 | 元素协同、多光环多诅咒 |
| Q4 | 野蛮人+圣骑士+死灵+游侠 | 物理、召唤、协同 |
| Q5 | 圣骑士+死灵+法师+元素箭术游侠 | 不假定能上阵重复职业；元素箭术游侠仍只弓 |
| SOLO5 | 五个职业各自单英雄单槽 | 各职业单人开局必须用实际已解锁能力 |

Q1–Q5需要正确的已解锁角色槽/技能槽存档状态，不能给正式档案强行注入四人/五槽。单人测试与四人测试不得共用一份绕过进度的生产存档。

## 3. 章节内容源数据不可重写

五章既有：42区域、189 Dungeon、42 Castle、231 POI、505独特楼层（3难度共1515楼层记录）。这来自**原五章地图与07执行包的来源快照**；本包仅以其为追踪边界，**不声称目前源码已有所有内容**。

Boss关键锚点：Act1 `ACT01:A08-C01` 安达利尔；Act2 `ACT02:A07-C01` 都瑞尔；Act3 `ACT03:B07-C01` 议会/墨菲斯托；Act4 `ACT04:D04-C01` 混沌五封印、三守卫、迪亚波罗；Act5 `ACT05:W08-C01` 三远古者、`ACT05:W09-C01` 巴尔五波。Act2–5候选Boss身份与数值审批状态依 07 包，并非全部正式锁定。

## 4. 三难度的数值准备条件

在生产Level、HP、Armor、K(L)、攻击力、怪物等级/角色等级/EXP倍率、装备词缀和掉率**没有批准并装入工程之前**，可运行的仅是TEST_ONLY数学与规则回归。真实三难度数值“PASS”需要每章有效档案与相应生产配置；不得以Act1复制的假怪物属性声称Hell通过。

## 5. 系统压力与配队公平

- 让玩家直观看到不同BD的优势，不要求队伍每场TTK完全一致。
- 按装备价值、点数、账号全局星图进度相近做对照；跨等级队伍需单独做经验规则测试。
- 对每队观察：输出、承伤、召唤战损、控制有效收益、触发次数、失败率和连续挂机稳定性。
- 不允许“仅选最快的一个随机种子”当做职业平衡结论。

## 6. 视觉与执行风险

- Mini 480×240下3~4英雄＋召唤物、怪物特效可能遮蔽锁定与击杀；必须有录像。
- AI激活延迟与小队散开已是现有规则；退让是否实现必须首先核查。
- 一维逻辑X/二维视觉Y；不允许因为测试夹具大场景迫使实现真实物理避障。
