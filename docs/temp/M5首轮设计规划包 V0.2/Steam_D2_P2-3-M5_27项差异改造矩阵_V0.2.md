## 二、旧规则的单一权威退役清单（不可双活）

1. 旧`HeroExperience`独立XP／等级差衰减／`while`自动升级 → 公共XP余额＋用户指定一级升级；旧存档兼容必须另设转换入口。
2. Armor常规物理减伤 → 唯一AR/DR对抗倍率；DMG1/2旧表示层可以保留但计算语义不得冲突。
3. `dungeon/poi/floor_plan/spawn_rule`多套怪物等级覆盖 → 仅Run `[Lmin,Lmax]`有最终决定权；关卡仍决定房间/敌人模板和Boss特性。
4. `party_slots`/`skill_slots`星图效应及旧技能装配 → 普通4席、4技能＋1特性；账号第五席接口与本轮星图区分。
5. `SpecId`做英雄唯一标识 → 实例ID；Buff、召唤、天赋、装备、编队及读档都必须承认重复职业。
6. `Reset`混淆全清、放弃、重生 → 三种不同事务和玩家反馈；Account/Run跨轮归属唯一化。

## 三、完整系统闭环首轮验收情景（工程实现后，不是此刻验收结果）

- 开始新轮：玩家选4名英雄（允许双相同职业），确认锁队；期间不得偷偷改编队。
- 自动刷怪：杀怪产公共XP/KP/金币/装备/卷轴/药剂；后台也只累积未花资源。
- 右侧独立操作：选具体英雄升1级；成功升级获得AR/DR与天赋点；换一件装备或5+部位批量换装；主动买Lmax；购买星图；手动攻城。
- 装备/消耗品：角色绑定装备入候选，回城先保护再卖；卷轴手动命中才扣库存；药剂使用中仍占槽，期满释放。
- 跨轮：首轮四章结束触发重生接口；Run重置、Account保留；放弃本轮不发通关奖励；读档恢复一致。
- 守恒与可观测：固定Seed对照战斗事件、XP/KP/金币以及Loot消耗；开/关观测不改变战斗结果。
- Lmin：未完成严格安全策略之前，真实玩家看不到可购买的Lmin操作；封闭测试允许制造反例并记录。
