# 03｜技能类型适配、17个代表技能与跨职业兼容

> **注意状态：** 17个技能是前一份P0-3执行包的**开发候选清单**，不是“全都已实现”；名称、技能ID只作为跨文档映射。玩家未正式批准的技能数值、动画、具体AI阈值不可凭本文件定稿。AI只确定“何时提出CastSkill请求”，效果和强度归已存在的技能/Effect规格。

## 1. 必须复用的技能目标大类

| 类别 | 必须回答的问题 | 目标合法性 | 行动原则 |
|---|---|---|---|
| 近战单体 | 目标是否仍可命中、在近战射程？ | 敌方实体 | 范围不够按现有Move规则，禁止瞬移 |
| 远程单体 | 目标是否合法、在射程且满足LoS？ | 敌方实体 / 弹道方向 | 主TargetLock稳定，技能临时目标可不同 |
| 多弹道/多段 | 发射方向与有效目标是哪些？ | 多个敌方实体 / 合法方向 | AI仅决定发射，不在每发弹丸回调里重复施法 |
| 范围AOE | 目标数是否达到收益门槛？ | 合法目标/范围中心 | 先候选过滤再稳定选择区域，不全图挑敌作弊 |
| 自身周围控制 | 是否真的有附近威胁？ | Self + 合格敌群 | 没有敌人不空放，不新增专用怪物仇恨 |
| 近战救场/嘲讽 | 该目标是否正威胁队友，距离是否可达？ | 限定范围与目标数 | 强制锁定由现有技能/TargetRuntime执行 |
| 主动治疗 | 是否存在合法缺血队友？ | 有效友军 | 依固定目标策略；不凭空恢复已死队员 |
| 持续光环 | 是否已装备、应维持、效果来源合法？ | Self/AuraRange | 多种同时共存，各自占槽，不每Tick重新释放 |
| 诅咒 | 目标是否缺少有效同种诅咒？ | 有效敌方单位或合法范围 | 多种共存，同种去重/刷新 |
| 召唤 | 本人召唤名额是否空缺？ | 合法召唤位置 | 已满不重复施放；召唤物跨房续存 |
| 尸体消耗 | 是否有当前房间未消费尸体？ | 尸体ID/位置 | Commit 才由唯一消费权威决定结果，AI不得预消费 |

## 2. 17个代表技能：可直接配置的条件语义

| 草案SkillID | 资格条件（示例，T值测试注入） | 建议临时目标策略 | 应跳过的场景 | 核心回归 |
|---|---|---|---|---|
| `BAR_BASH` | 合法近战敌人、Ready | 当前主锁定，失效才复用既有重选 | 不在近战射程、不可攻击 | 近战距离+CD/普攻共存 |
| `BAR_TAUNT` | 队友受到当前范围合法近战威胁/明确特殊命令 | 有限数量合格威胁怪物 | 无需转移的怪群、目标范围外 | Forced不破坏接敌稳定 |
| `BAR_WHIRLWIND` | 有当前有效近战敌群/行动路径合法 | 已批准的移动方向+路径范围目标 | 没有效目标、被控或路径不合法 | 动作期间不反复请求技能 |
| `PAL_SMITE` | 目标在近战范围且角色可行动 | 当前主锁定 | 目标越界/死亡 | 不无距离“拦截” |
| `PAL_PRAYER` | 已装备且当前光环需要激活/保持（具体生命周期待审计） | 自身+合法光环范围友军 | 已正确维持时不可每Tick重新 Cast | 治疗只按真实HP缺口 |
| `PAL_FANATICISM` | 已装备且激活资格成立 | 自身及符合条件友军/召唤 | 已维持，无需反复重开 | 同时与Prayer并存、各占槽 |
| `PAL_CONVICTION` | 已装备且激活资格成立 | 光环范围内合格敌人 | 已维持不重复附加独立乘区 | 与降低抵抗共存 |
| `SOR_FIREBALL` | 至少一个合格目标，AOE收益门槛可配置 | 覆盖最多合法敌人的候选落点/主目标 | 无敌人、不可合法命中 | 火伤不自动燃烧 |
| `SOR_FROST_NOVA` | 施法者附近近战威胁成立（或覆盖满足门槛） | 自身中心 | 没有近敌 | 不强制打断受击退让/当前前摇 |
| `SOR_CHAIN_LIGHTNING` | 有有效起跳目标；是否要求至少2敌人是可配置条件 | 本次合法弹射收益最佳起点 | 无合法首目标或越界 | 跳数、唯一命中与Proc独立 |
| `NEC_RAISE_SKELETON` | 已装备且存活骷髅未达到指定数量、位置合法 | 合法生成位置 | 已满/场景不可召唤 | 不耗尸体、跨房HP保留 |
| `NEC_AMPLIFY_DAMAGE` | 目标尚无有效同种诅咒或可合法刷新 | 当前重要目标→缺覆盖敌人 | 有同种足额覆盖且未到刷新条件 | 多种不同诅咒可共存 |
| `NEC_LOWER_RESIST` | 同上，合法敌人可诅咒 | 元素输出队优先关注的合法目标（实际AI依测试配置） | 同类已经有效覆盖 | 与Conviction进入统一抗性解析 |
| `NEC_CORPSE_EXPLOSION` | 有合法未消费的当前房间尸体、敌人处于有效爆炸范围 | 合法尸体ID | 无尸体/尸体已消费/无受益目标 | 仅SkillRuntime/尸体权威可以消费 |
| `RAN_MULTISHOT` | 弓类武器已装备，存在可射击的合法敌人 | 有效敌群方向 | 没弓、无有效目标 | 1D逻辑+二维演出不等于2D弹道命中 |
| `RAN_GUIDED_ARROW` | 弓类武器、有效单体目标、Ready | 当前合法追踪目标 | 目标不合法或射程外 | 跟踪命中与主锁定分离 |
| `RAN_VALKYRIE` | 已装备且女武神数量未到上限 | 合法生成位置 | 数量已满/不能召唤 | 独立召唤HP/容量/跨房跟随 |

**不能默默给职业增加新的技能：** 祈祷不是紧急高强度治疗、狂热不是全职业通用CDR、旋风不天然增加接敌容量、火球火伤不天然燃烧、女武神近战不代表游侠本人可以使用近战武器。

## 3. AI 典型组合验证

### A：野蛮人+法师被漏怪追击

1. 小队遵照现有入场散开和敌AI启动延迟，进入正常合法战斗状态。
2. 野蛮人基础接敌容量与怪物Normal/Overflow继续由既有敌AI管理。
3. 漏怪近战命中法师→通用退让模块可在合法窗口申请Move，**不强制**让所有敌怪重新选目标。
4. 野蛮人嘲讽如已装备、CD完成、满足距离/目标数量和CastCondition，提出CastSkill；强制转移归技能Effect。
5. 法师冰霜新星若附近有威胁，可在**可开始新行动时**施放；不得打断其当前不可取消施法或退让。

### B：圣骑士多主动光环+死灵多个主要诅咒

- 圣骑士在合法槽中同时装备祈祷、狂热、信念，**三项允许维持**，各占一槽，不要求每Tick重新Cast。
- 诅咒伤害加深、降低抵抗可同一目标并存；应用已有Buff叠加分组，不应互相驱逐。
- 同种重复来源按G02策略去重/取强（细节需已有Buff合同核实）；改变光环来源、范围后撤销准确对应 Modifier，不允许残留。
- 骷髅在狂热范围内如果符合资格可受益，但临时光环不从主人快照再继承一次。

### C：先召唤骷髅，再尸爆清群

- 死灵技能槽中同时有骷髅和尸爆；不足上限可在合法窗口补骷髅；尸爆没有尸体时**不入候选**。
- 骷髅杀死正式敌人，死亡事件按原规则生成唯一尸体；在下一合法窗口AI可以申请尸爆。
- 两个尸爆请求竞争同一尸体时，只允许一个成功消费；若第二个在Commit前目标失效，按审批后的当前技能取消语义结算，不能在AI里先扣尸体。
- 尸爆造成的死亡与后续BD链效果只由已有TriggerRule/EffectQueue结算，AI不参与一层层派生施法。

### D：游侠持续弹道+受击退让

- 远程游侠只有弓技能，不引入标枪动作；炮轰如果后续增加，持续动作不能被普通施法策略强制改写。
- 近战怪直接攻击后，若受击退让模块合法，角色在安全边界退让后再恢复原技能优先级扫描。
- 导引箭的投射物飞行不会占用角色持续的施法动作；Commit 后原目标死亡时的飞弹命运由既有弹道规则决定。

## 4. 不批准自动添加的新机制

- 不做“法师必先冰霜新星”“游侠必打最低血”这类未确认硬编码职业AI。
- 不新增手动拖拽式技能宏 UI、复杂 DSL、自动切天赋、动态升级技能。
- 不开发战斗之外的刷图/切地图/回城指挥，保持 IdlePolicy/GameSession 边界。
- 不把主动光环维持语义偷换为纯被动免费获得：**技能槽占用是正式成本**。
- 不因技能属于诅咒而互斥：不同诅咒共存是正式规则。
- 不为提高AI「聪明」而修改敌方 TargetLock、接敌容量、护甲伤害公式或召唤物奖励归属。
