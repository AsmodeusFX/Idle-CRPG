# Steam D2｜S08 十小时首轮星图完整内容与拓扑 V0.9

日期：2026-10-25｜设计Owner｜状态：**[P]完整内容提案 + [H-S08]金币测试参数；非正式生产配置，不改变执行AI WP4–WP9既有授权。**

## 0. 目的、继承的规则和不继承的内容

目标是在**[C]标准四人队首轮约10小时、前四章、31座区域城堡（25主线／6可选）、怪物Lv1–31**的结构内，设计一套玩家愿意反复点击、而不是只有临时数值开关的Run金币星图。分章时间暂按**[P]90／165／195／150分钟**，不把时刻作为硬解锁门槛。

直接继承[C]：

- 本轮星图使用**Run金币**，重生清空；Account永久职业与第五席不属于它。
- **4固定技能＋1独立职业特性树**；特性资格由星图**按ClassId单独购买**，同职业所有上阵实例共享资格，但各英雄自己消费天赋点；购买资格不自动学T01。
- 英雄公共XP由玩家手动分配升级；怪物Lmax由玩家用**KP**逐次购买；全员AR/DR校验；城堡由玩家主动挑战；星图不自动代操作。
- 只有技能天赋决定职业专属攻击形态，星图只提供**跨职业的队伍属性、成长效率、容量和系统功能**；不通过星图恢复旧技能装配槽、额外队伍席位或Armor。
- Lmin购买继续关闭；星图不控制怪物等级、刷怪数量、精英概率、装备掉落品质，这些是KP及对应系统的领域。

本稿以V0.2的31定义／78阶**作为盘点起点**，继承S06/S07 V0.8已修订的野蛮人／游侠／法师／圣骑士核心特性（内容仍为[P]）。**31个节点并不等于31次购买，也不代表31个已被工程实现的效果。**

## 2. 节点网络：前置是“某节点已买到指定Rank”，不是“另一职业资格”

约定：`O01@2`=O01达到Rank2；`A|B`表示满足其一即可；`ROOT`不需要前置。图的显示采用中心共享节点向九条分支放射，而不是九棵相互隔绝的大树。下面是**完整且无循环**的逻辑连接：

| 分支 | 逐节点关系（购买依赖） |
|---|---|
| 进攻 | `ROOT→O01(3)→O02(3)→O03(3)`；`O01@2→O04(3)`；`O03@1 或 O04@1→O05(2)` |
| 生存 | `ROOT→D01(3)→D02(3)`；`D01@2→D03(3)`；`D02@1 或 D03@1→D04(2)` |
| 评级 | `ROOT→R01(3)` 与 `ROOT→R02(3)`，不捆绑其他战力节点 |
| 成长 | `ROOT→G01(3)→G02(3)`；`G01@2→G03(2)`，全队赠点不强迫先买精英XP |
| 职业 | `C-BAR: O01@1 或 D01@1`；`C-RAN/C-SOR: O01@1 或 G01@1`；`C-PAL: D01@1 或 O01@1`；`C-NEC: G01@1 或 D01@1`且Account职业先解锁 |
| 卷轴 | `O01@1 或 G01@1→S01(3)→S02(3)`；`S02@2→S03(2)`（未来自动卷轴） |
| 药剂 | `D01@1→P01(3)→P02(3)`；`P01@2→P03(2)` |
| 冒险 | `ROOT→A01(3)→A02(3)→A03(2)` |
| 财富 | `ROOT→F01(4)→F02(3)`；`F01@2→F03(3)`（离线相关） |

本稿只规定**购买逻辑图**，不将上述字符串直接冒充Godot布局坐标；视觉摆位以节点之间连接易读、先后关系清楚为准，WP8实际UI截图要能显示当前Rank、下Rank价格和生效对象。

### 2.1 四职业核心资格：第一章“可以看见和可能买到”，不是强制四个全买

| 星图节点 | 同一轮购买后的生效对象 | 能在英雄页继续做什么 | 严格禁止 |
|---|---|---|---|
| `C-BAR` | 所有在队野蛮人 | 独立投入「狂战本能」特性点 | 自动点出战吼/旋风或给额外主动槽 |
| `C-RAN` | 所有在队游侠 | 独立投入「狩猎技艺」点 | 买一份给不同实例重复扣费 |
| `C-SOR` | 所有在队法师 | 独立投入「元素法则」点 | 强迫三元素按固定轮换释放 |
| `C-PAL` | 所有在队圣骑士 | 独立投入「持续光环」T01，才可真正开光环 | 买资格就直接开光环或给无关职业 |
| `C-NEC` | **首次正式重生之后**且有上阵死灵时 | 允许学习死灵特性树 | 首轮为锁定展示，不计入购买容量 |

设计意图：第一章约中后段[P]通过已购的一个基础节点让职业资格出现在近期目标中，玩家可以优先选一位有充足天赋点的职业开门；第二章再为其他在队职业补买资格。**不以章节硬锁资格**，只由合法前置、金币与职业拥有状态判断。重复职业队仅买一次资格，其余金币可投向不同分支。

## 3. 31个定义的效果归属与价值检验

逐条字段、MaxRank、完整前置、H金币价格、候选效果、运行时风险详见附件`S08_31星图定义与前置候选_V0.9.csv`。以下是必须着重审议的内容：

1. `O01/O02/O03/O04/O05` 递进时，新增可观察场景分别为基础伤害、普攻节奏、暴击、元素组合、精英目标；没有“全队所有技能各自产生一个新机制”的越界。
2. `D01/D02/D03/D04` 分别服务血量、格挡、抗性、既有合法治疗；`D04`是治疗增幅，**不能凭空产生治疗来源**，无治疗职业或药剂时价值显著下降，应显示预期受益。
3. `R01/R02`必须显示谁距离下一档AR/DR最低门槛还有多远；**无星图评级的自然升级路线仍需可达Lv31**。[H-B1]评级曲线不能由此正式锁定。
4. `G01`合法击杀公共XP加成，`G02`提出合法精英奖励附加XP，`G03`给当前Run上阵的各英雄每阶+1未分配点。[P]G02需要防止同一怪重复领奖，并允许不同合法遭遇正常重复；与KP收据分账。[P]G03若买满两阶，S07候选Lv25每英雄24升级点将变为最多26个可投入点，八套24点构筑只是可行示例，**不再是绝对毕业点数上限**。
5. `C`只开资格；职业核心机制和两种互斥路线仍来自每名英雄的天赋树。[C]
6. `S01/S02`在卷轴真实库存／伤害消费能力具备时可投；`S03`为自动卷轴能力保留，不把“单体手动卷轴已经实现”推论成已经可以自动施法。[P/O]
7. `P01/P02`在药剂真正可用时改变有效Tick时长与实际强度；`P03`两阶暂拟4→6→8，需WP6最终能力与UI共同确认，不得虚构空位或允许同种药剂双开。[P]
8. `A02/A03`只优化合法自动拾取、非战斗周转，**不能自动换装、出售受保护候选、升级英雄、买Lmax或挑战城堡**；若运行时没有单独可观察的周转成本，应删除或合并，不能为了31定义填无效节点。
9. `F01/F02`只影响金币和经确认售卖；`F03`只影响合法离线结算，不应在完全在线的一轮中被当成必需购买，也不能自动触发闯关或升级。[P]

**关键防偏航**：31个定义是本轮完成的*内容候选集合*，不是“必须强保留31节点”的产品目标。一旦S09–S13证明有功能没有价值或运行时不可承接，应删减/替换并同步重算60次购买容量，不允许用有名无实的Rank凑点击。

## 4. 四章购买与职业学习的联动

| 章节 | 功能目标 | 推荐主投分支 | 特性资格节奏[P] | 不应发生的事 |
|---|---|---|---|---|
| 1，0–90min | 最初几次低价成长、第一次队伍结构判断 | O01/D01/G01/F01及少量R/A | 第一章中后至少**一种在队职业**可望取得资格 | 第一个可买资格藏在另一个职业资格背后 |
| 2，90–255min | 第三技能与T逐渐成型、药剂卷轴介入 | C、D02/O03、G02、S01、P01/F02 | 四职队可完成余下职业资格，双同职不重复付钱 | 购买资格自动学会特性／增益不生效 |
| 3，255–450min | 第四技能、互斥分支、持续高频成长 | O04/O05、G03、P02/S02、D03、R | 星图成为技能差异的后援，而非替代S07天赋 | 缺少合法怪物KP路径却靠星图强迫通关 |
| 4，450–600min | 既有构筑深化，跨深地牢保持稳定 | 后段高Rank、D04、P03、精英增益 | 特性已学与装备搭配接受终章考验 | 用末章天价Rank填满时间；离线节点对纯在线者强制购买 |

**首次资格购买时点仍是[P]开放设计**。若实际金币投入导致正常玩家直到第三章才第一次看到职业核心，应优先调整星图资格的可达性及收益，而不是直接把职业幻想推后。
