## C. 分主体验收条款

- 工程执行AI：每包构建、Core、Godot、回归和证据索引均需真实产出；未测明确标示。
- 设计Owner：材料回传后评审行为、数据合同、实际UI截图、玩家操作负担，并记录`PASS/PASS_WITH_OPEN_ITEMS/BLOCKED/FAIL`。
- 用户：最终裁决关键产品取舍及保留的阶段验收关口；设计Owner不能把[H]/[P]升格为[C]。
- **P2-4总功能闭环通过 ≠ P2-5A正式数值通过 ≠ P2-5B体验通过。**
