## 3. 后续设计Owner任务链

1. 本轮：将已批准的旧档冻结迁移与怪级快照规则转为执行AI可操作的修订/补证回传文件；核对WP4–WP9跨系统行为和验收边界；提交第二批待授权包。
2. 收到WP0–WP3补证后：核对旧档、真实UI与实例隔离；在**原首批Review**追加结果与剩余缺陷。
3. 用户批准第二批某范围后：执行AI按授权实施；设计Owner按提交的真实证据逐包验收、更新统一设计认知，不日常卡审批。
4. P2-4闭环通过后：与用户专项讨论单轮时长、成长频率、TTK、掉落/金币/星图/KP等，制定P2-5A唯一正式数值模型。
5. 执行AI在真实Core中验证账本/公式/流程正确，再通过固定Seed和长跑/真实操作策略验证体验达标；Godot关键UE实测。

## 4. 永久防偏航项

- 首批已完成的核心语义：开局1–4英雄同职可重复、锁队；公共XP无衰减手动指定升级；AR/DR替换旧Armor真实伤害因子；Run KP＋统一怪级；Lmax与城堡手动购买/挑战。
- 第二批本轮**必须**完成真实装备、卷轴、药剂，不因工程忙变成空UI；星图代表节点、技能+特性需能真实操作；重生与有限离线有可复现最低链路。
- UI主界面七区硬约束：顶部功能、战斗区、战斗下沿横向卷轴、右上货币/右侧交互、左下队伍＋技能CD、右下默认4药剂槽预留8；不无解释删除现有功能。
- 旧档冻结隔离不代表账号永久英雄资源；正式重生不能静默吞存档；KP Lmin永久购买没有安全模型前持续关停。
- 正式数值、成就商店、所有职业完整技能树、丰富地图事件，不作为第二批首轮功能阻断，也不擅自提前实现。
