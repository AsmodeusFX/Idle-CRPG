## 已可作为真实认知的结论（有边界）

1. [E+设计推算] 城堡`A02-C01` Lmax≥5且需前置；Run Lmax逐笔+1、每位英雄独立AR/DR门槛。4人从Lv1到Lv5共16次英雄升级+4次Lmax购买=20次成长操作。这个**操作次数推算**不依赖是否能快速获得XP。
2. [H] 720公共XP/360击杀/90–120房是按每级费用18×等级、击杀2XP、无XP增益/怪级与房间分布变化的**静态基准**，不是玩家实际必须击杀的精确值；星图XP、怪物实际等级、事件与多次重复会改变它。
3. [H] “HP35–55、攻击22–30、两击1.7秒”只是粗略单体算术，未涵盖AR/DR、四人同时出手、技能CD、技能范围、行进时间与真实清房流程。用户感知的弱怪与技能无法完整展示保留USER_OBSERVED；**真实TTK尚未验证**。
4. [E] C3四人场剩10万+公共XP而等级约15–16，主要由实验每回流只执行一次单人升级造成；不得据此制定更贵的XP升级曲线。生产逐次升级是[C]，是否提供一次交互多次升级是后续UE选项。
5. [E] UI与星图可读性被用户评为未通过；其事实不被Godot smoke PASS覆盖，另记体验延期，不在本次只读审计实施。
