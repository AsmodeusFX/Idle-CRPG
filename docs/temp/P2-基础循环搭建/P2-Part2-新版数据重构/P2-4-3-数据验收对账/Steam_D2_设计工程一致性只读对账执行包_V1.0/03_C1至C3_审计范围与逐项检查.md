### 逐项清单最低输出数
- C1-A：至少16条技能、4条T、98条天赋，数据在`recon_design_id_crosswalk.csv`中逐ID；不得只写“98通过”。
- C1-B：31设计节点全部列示（含暂缓/禁售/QA），78设计阶的投影可引用现成B0材料的复核哈希，至少抽检门槛Rank与57/55完整路径。
- C2-A：393静态键及226/31运行消费入口须核对来源；可以引用已复跑且指纹一致的既有逐键表，首次失败、Boss、城堡威胁要独立跟踪。
- C2-B：24实际物品组合＋4被裁决覆盖、31怪级行、5卷轴＋4药剂必须有消费者；不得把CHARM_HP或旧品质ID当作生产存在。
- C3：实际运行还未有四章成功记录，绝不以静态11189次必经击杀直接推断实跑达标。
