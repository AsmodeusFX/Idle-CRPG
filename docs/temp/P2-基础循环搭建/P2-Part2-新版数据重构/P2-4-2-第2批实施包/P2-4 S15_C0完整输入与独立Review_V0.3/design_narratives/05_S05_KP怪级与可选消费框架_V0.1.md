# Steam D2｜S05 怪物等级与KP的31档消费设计 V0.1

日期：2026-10-25｜设计Owner｜状态：[P]内容与经济规划；实际数值举例全部为**[H-B1]**，不是正式配置，也不改变WP4–WP9授权。

## 1. 设计问题和固定规则

- [C] 首轮共有31座区域城堡（主线25，可选6），故当前怪物等级容量1–31；**但城堡准入值可以重复**，AND并行城堡同层级、可选城堡对齐最近主线层级。
- [C] 怪物等级抽取仍用全Run单一`[Lmin,Lmax]`；购买每档`Lmax`由玩家主动完成，递增1级并检查四人各自评级与KP；城堡还检查P0地图前置，不要求实杀同级怪。
- [C] `Lmin`永久购买维持关闭；既存怪物实例不改等级，未生成内容按最新范围抽怪。
- [P] 城堡固定进度层级而**非挑战先后动态定价**；避免玩家先打并行A而提高B的准入。

一个必须区别的数字关系：从初始`Lmax=1`到`Lmax=31`需要 **30次实际购买**，但是这不代表有30个互不相同的必经城堡门槛。非城堡锚点升级依靠普通怪组合、经验、KP和掉落生态体现价值。

## 2. KP主消费H-B1模型

| 项 | 举例 | 意义 |
|---|---|---|
| 合法击杀KP收益 | 1KP/怪 | 沿用工程原型作为**临时预算单位**，不是批准的正式掉落 |
| 下一档Lmax价格 | 当从g−1买到g：`K(g) = 14×(g−1)`，g=2..31 | 线性上升，30次总价6510KP；与此前“每次10”原型不同 |
| 晋档资格 | 所有在队英雄的自然或实际AR和DR ≥ 怪物g档标准10g | 每人都查；其中自然成长至少可以达标，装备不作前置 |
| 不足KP | 仍可刷当前合法怪池持续获得KP | 不会锁进下一档才能获取晋档KP |
| 提高Lmin | 本轮禁用 | 即使攒有多余KP也不能用这一功能消耗 |

**KP阶梯预算：**第1章升到g8用392KP；第二章g9–17新增1512KP；第三章g18–26新增2646KP；第四章g27–31新增1960KP；合计6510KP。此处是**全队升档总价**，不是每英雄重复付费。

## 3. 一轮还必须有第二类KP价值（先设计，不扩大编码）

只有30笔Lmax购买，无法持续承载10小时的KP选择。以P0静态击杀规划12480计算，假设每击杀1KP，支付6510KP后仍余5970KP。该差额说明**需要更丰富的怪物/掉落生态消费**，但不能把它视为已经存在的运行时能力。

[P] 候选三类永久至本Run结束的怪物生态修饰：

| 消费方向 | 玩家得到的选择 | 主要风险，必须等内容/经济设计复核 |
|---|---|---|
| 更高怪群规模 | 更高产出、战斗可看性和负载压力 | KP→怪数→更多KP的自强化，需封顶与性能预算 |
| 额外战利品质量倾向 | 更值得刷装备而不是仅升级等级 | 可能绕开装备掉落和金币消费预算 |
| 精英遭遇权重 | 用更有挑战的战斗换取收益 | 必须有精英生成与奖励口径，不可用无奖励精英惩罚玩家 |

[H-B1] 用于估算的**可选Rank价格**：每类4阶，`Rank r`售价`110×r²`，即110/440/990/1760KP；一类全买3300KP，两类全买6600KP。理论剩余5970KP可支撑若干但非全部路线，形成消费取舍。**这些阶数、效果、价格都未获正式批准，WP3当前仅实现Lmax购买，不得声称这些修饰已经可玩。**

推荐优先级：先验证“掉落质量倾向”和“精英遭遇权重”的内容价值，再考虑会自我放大KP总产出的“怪群规模”。S09–S13填足实际怪物、装备与掉落后再决定真正可交付的Rank效果。

## 4. 31级与25必经城堡、6可选城堡如何共存

1. 章末候选Lmax锚点仍暂用 `8/17/26/31`，这是S01建议目标、非P0地图固定评级。
2. 串行城堡锚点静态升高；并行AND两座可共享同一个`CastleRequiredLmax`；可选6座分别共享其开启窗口的主线门槛，不被算成新的强制晋档。
3. 不能用城堡挑战先后作为怪物等级动态重排因子；比如玩家在并行A提升Lmax后再打B，**B的准入门槛不改变**，但它实际遇到的怪物仍按最新Lmax抽样（已生成快照除外）。
4. 同组并行A/B可能先完成任一座，但AND合流始终等两座都完成；不要把顺序自由误认为只用打一个。
5. 若要使全部31档都有玩家可观察的差异，依靠资源与战斗池的纵向变化，不额外按城堡强制一套不同怪级。

## 5. 主要断供与经济边界

- **最低可行路径**：即使完全不买可选KP修饰，只靠普通合法怪奖励与自然升级，应可逐档买到31。
- **资源准入不环依赖**：当前g不足时仍能在`[1,g]`刷XP和KP；不能把下一档所需资源只放在下一档。
- **额外KP消费的机会成本**：如果玩家提前买满可选修饰，可能短暂缺KP买Lmax，但仍有可观察的合法回刷收益，并需要给出下一档费用提示；不能永久断供。
- **低效队伍**：多人队存在评级最慢实例，必须提供具体角色与AR/DR差值反馈；不自动替其分配XP。
- **Lmin安全**：如果未来研究允许提高Lmin，必须另有保底实测与恢复策略；此版本不得开放。

## 6. 需在S08–S13继续确定的内容

怪物等级奖励还应关联金币、装备和精英战利品，但**不能自行沿用P1旧掉落数值**。S08星图的金币消耗独立，S11装备收益驱动这些KP生态修饰价值。到S13才形成真正联立的KP/金币/XP/道具收支预算；P2-5实际观察后才审批入正式配置。
