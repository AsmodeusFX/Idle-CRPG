## C3-1　真实事件流水与可复现策略

扩充而不复制既有`AssetAudit`，实现带稳定键的XP/KP/Gold、技能、星图和装备消耗品逐笔事件；同种子相同策略与输入版本应能确定性重跑。正确区别合法重复DungeonEntrySerial和同一击杀收据重复领取；完整模拟策略至少包含逐名手动升级、合法星图Rank购买、Lmax资格检查、装备/耗材手动行为。任何策略没有动作应明确记录`ACTION_NOT_MODELED`而非悄悄代替玩家自动决策。

## C3-2　参数隔离试验和四章场景

在独立QA输出目录运行静态纠偏表、31怪级候选表与受控增益；先以小Seed发现消费者缺口，再按`C3_实机模拟实验矩阵_P.csv`跑四职业与重复职业、低操作与积极管理、不走可选Dungeon、装备不佳与耗材不用等真实对照。Lmin仅QA风控，正式玩家命令与存档继续拒绝。

**关键反例：**(a) Run Lmax升档后已生成Room等级快照不变；(b) XP升Hero只改变点名实例；(c) Gold星图倍率只影响购买之后的真实杀怪；(d) C1-B纯在线不以F03充实质次数；(e) optional不计基准通关；(f) 4→8药剂槽未经批准不得实施；(g) 章末金币与实际购买时点资金不透支；(h) 四Boss失败/重试真实推进与复活路径；(i) 装备零售出、只拿普通装备仍可推进；(j) G03/S02/P03绝不真实出售。
