# C3｜四章经济重新联立：修正后主线预算与三账风险

## 1. 来源、性质、公式

- [C] P0保留主线/可选区分；首轮四章约10小时；英雄手动升级，唯一公共XP，Lmax用KP逐级购买；正式Lmin关闭。
- [E-来源] C2原P0对账：116座必经Dungeon历史8207杀、20座可选Dungeon历史1291杀；城堡2982杀是S11旧估算，尚未完成P0城堡逐房生成核实。
- [H] S13每章XP收入7540/16193/27798/30375，原先建立在2367/2925/3718/3470静态击杀上；本版将每章**XP每杀平均不变**后同比改为2289/2724/3214/2962。计算：`XP_new = XP_S13 × K_main / K_old`。这不是逐怪级真实XP重算。
- [H] KP每合法击杀1，与S04章节Lmax累计支出392/1512/2646/1960；金币击杀均价1/1.5/2/2.6；不计装备首次城堡保底，账面金币出售取S11无城堡首通120种子**平均出售金**按章与修正击杀率线性缩放，**只做敏感性代理**，没有重新运行装备随机模拟。
- [H/P] 星图**替换为最新C1-B**两条路线57/55笔，21650/20750金币，不再使用S13过时的20560/20530；假设所有被购买节点有真实消费者，否则应相应移除购买与效果。
- [H] 测试比例100%、90%、80%、70%，完全不做可选Dungeon、离线、首次城堡额外装备、教学耗材发放或星图倍率；不使用消耗品加速战争。P0历史预算不是合法生成规则或在线效率证明。

## 3. 重新复算的公共XP与KP阶段余额[H]

**按100%修正必经击杀**，一套四人升级目标费用不变，章末累计XP余额约为：`+3092 / +2772 / +6442 / +18210`；KP余额：`+1897 / +3109 / +3677 / +4679`。

**按80%修正必经击杀**，章末累计XP余额约为：`+1633 / −1703 / −2839 / +3744`；KP余额：`+1439 / +2106 / +2032 / +2441`。因此第二和第三章存在阶段性XP缺口，第四章正余额只是**假设已合法推进的条件性计算**。不能拿第四章的正数掩盖前面不能如期购买升级的问题。

截至第二章满足Lv14代理目标，需要约**87.6%**的修正静态平均XP覆盖率（原S13模型误计可选时82.6%）；截至第三章约**86.1%**。实际等级抽样、星图加成及重试都会改变门槛。

## 4. 两阵容最新星图金币模型[H]

- 甲 四职业各一：57笔，章节费用2280/3630/6330/9410，总计21650。
- 乙 双游侠双圣骑：55笔，章节费用2290/3410/5020/10030，总计20750。
- 100%修正必经、**仅击杀基础金、不计出售**：甲全程末余额约`−1145`；即使满额静态击杀也不能按时买完57笔。此处击杀金本身也是[H]，不是正式保底下限。
- 100%修正必经、**额外按S11无首通装备出售金的线性代理**：甲期末约`+3514`，最低章末余约`+171`（第一章），仅说明数学可行，未验证实际掉落出售。

## 5. 哪些修正**不能**直接用于定价

1. 2982“主线城堡”规划杀不等于真实生成，C2-A接入后需重采真实Boss与守卫数量。
2. 旧S04的公共XP平均随怪级均匀抽样，该前提未经真实Run `[Lmin,Lmax]`按合法遭遇时间点核实。
3. XP/KP/金币星图真实购买将动态改变后续收入，**只允许事件级后续收益追踪，禁止全程一次性乘总加成**。
4. S11掉装与售卖是**路径依赖**（同部位更好候选保护、装备品质和出售时机）；线性折算仅敏感性探针，正式值须运行S11式多种子模型或Godot。
5. 11,189/600=18.65杀/分钟是规划平均，不是玩家已达到的击杀速度；Boss失败、移动、回城整理、决策与暂停均未模拟。
6. 55–65有效购买仅对具备消费者的标准阵容有条件；单人、单职业、无治疗、纯在线不能被强迫购买无效节点。

## 6. 数值建议[P]，不是正式改参

优先接入Run真实怪级分布、同一击杀事件的XP/KP/金币来源、购买时点、装备保留及真实Boss时长。先判断第二章卡点来自怪数密度、击杀效率、XP价目、怪级样本还是策略错配，再考虑调整`herolevel`、每怪级XP、星图XP获取系数或章节掉落权重。不能把可选地牢强行变成必经，不能直接将KP剩余额全部自动花掉，更不应恢复等级差XP衰减。
