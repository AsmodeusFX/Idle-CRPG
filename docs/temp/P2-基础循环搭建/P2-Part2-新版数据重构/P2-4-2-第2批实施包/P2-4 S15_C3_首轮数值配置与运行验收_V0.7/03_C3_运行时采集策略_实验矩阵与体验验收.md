# C3｜运行时观察、实验策略与10小时验收

## 1. 运行环境门槛

**实验必须等待所需输入具备：**C1-A/C1-B各自Review的效果消费者已验证；C2-A主线刷怪及四Boss行为已进入真实生成；C2-B实际掉落和装备/耗材效果已通过交付或清楚标明缺席。任何缺席组件不允许用伪收益替代；可以先运行隔离定向测试，但不能给完整10小时验收打PASS。

## 2. 事件与来源账本

工程Review已有`AssetAudit`、`asset_ledger.csv`的初始能力[E]。C3是在其基础上**追加必要维度与来源类型**，不要复建第二个财务权威。详见`C3_运行时逐事件采集字典.csv`。全程保持RunId/Seed/章节复合POI/Floor/Room/DungeonEntrySerial/MonsterOrigin/MonsterActualLevel/PartySignature；跨存档Run序号和事件ID唯一。

**三项必须验证的守恒**：

`EndXP = StartXP + ΣXPIncome(逐笔实际) − ΣHeroUpgradeXpCost`；

`EndKP = StartKP + ΣLegalKPIncome − ΣLmaxPurchaseKP − Σ其他已批准合法KP消费`；

`EndGold = StartGold + ΣKillGold + ΣSaleGold + ΣChestGold + ΣOfflineGold + Σ其他合法收入 − ΣStarGold − Σ其他批准费用`。

装备和消耗品必须按物品/库存数量守恒，不把事件数等同数量；物品掉落遭四槽拒收与装备合法出售按不同事件计，装备先产生后出售，不应重复。离线单独归类，不计入在线等效Boss战耗时；补发、重试和中断均不得重复领取。

## 3. 实验方法与策略[P]

见`C3_实机模拟实验矩阵_P.csv`。先跑**少量固定Seed冒烟＋确定性对照**，随后对两个标准四人队各跑多个Seed观察实际分布。建议初期每策略≥30 Seed用于暴露大问题，正式分位数评估逐步扩为≥100 Seed（建议，不是硬性批准门槛；由工程执行成本决定），不能将模拟器同Seed 30次重复当作独立样本。

玩家策略必须记录为显式代理动作：主动逐名升级、分配天赋、买合法KP、按C1B路线买星图、手动穿装备、手动卷轴/药剂、主动城堡。`greedy`仅说明QA脚本角色选择，不得偷偷开启生产自动升级/自动消耗。每10/25/45分钟检查是**模拟用户机会**，而非游戏中必需定时器。

主线无可选是**基准**；半探索/全探索额外组只计算对进度的附加收益和时间，不能用可选区收入保证必经路径。80%/70%覆盖率只在静态压力试验或人为降低合法遭遇数量的QA夹具中使用，不得伪造“实机实际击杀率”。

## 4. 时间量度与成功含义

`ActivePlaySeconds`(游戏前台实际Tick)、`WallClockSeconds`、`OfflineSettlementSeconds`、`CombatSeconds`、`MovementSeconds`、`TownDecisionSeconds`分开；四章进度用第一次实际通关时刻，不把仅闯入第四章或被QA前置通关标成成功。

**设计目标**：整轮约600分钟[C]；90/165/195/150分钟只是章节分配[P]。建议先用P50/P90与首尾时长区间对照目标，用户正式批准容忍区间前，不能用诸如“P50≤600”作为硬性通过宣称。

对每章输出：(1)成功通关Seed数及失败分类；(2)实际主线有效击杀、等级直方图、速率；(3)最弱队员Lv/AR/DR；(4)KP每级购买时间；(5)XP余额与下一次升级成本；(6)星图实质效果Rank及金币累计；(7)装备主属性增长、出售来源；(8)卷轴药剂拾取、使用和满槽丢弃；(9)Boss P50/P90 TTK、胜率与重复次数；(10)右栏主动点击次数及平均/高峰密度。

## 5. 体验检查不等同于财务守恒

- `G_DATA`：字段、合法来源、账本守恒、随机一致。
- `G_PROGRESS`：英雄准入、四Boss、Lmax路径、可选剔除与重试都不出现不可恢复死锁。
- `G_VALUE`：55–65 Rank只在具消费者且用户自主选中的标准四人队中按真实Effect验证，未通过消费者的Rank不能凑数。
- `G_TTK`：Boss和地牢节奏需要真实战斗、UI操作与视觉Review；不能仅拿PlannedKill与代理TTK作依据。
- `G_10H`：完成四章且经过设计Owner独立Review和用户体验裁决后才能标正式通过。

## 6. Lmin风险隔离

正式玩家`Lmin=1`和所有购买入口关闭保持[C]。仅QA通过现有`QaRiskRange`等隔离入口测试“全员最低等级锁”[P]候选、失装、零Buff、死亡/复活、购买后被削弱、几次连续失败和存档不允许写入正式非1 Lmin。当前C3不得要求工程开放Lmin。
