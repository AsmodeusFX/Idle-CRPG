# P0原表直接核验与计数口径（2026-10-26）

本版独立打开原始`refs/P0-地图规则搭建.zip`的ACT01–ACT04 `POI`与`FLOOR_PLAN`文件，不使用S10推算表代替地图来源。

- 前四章P0共167个POI，全部为136个Dungeon和31个Castle；本包`C2A_393场地与楼层统一绑定索引_P.csv`全部命中原始P0的章节+POI复合键。
- P0包含314个**Normal难度**POI楼层，其中136个普通Dungeon合计226个Normal层，剩余城堡88个Normal层。本包逐一核验226层的章节+POI+楼层索引与原压缩包一致；另外88个Castle层归31城堡既有阶段结构，不错误计入C2-A的226普通地牢层预算。
- 原P0还有Nightmare/Hell楼层，非本轮首轮目标；历史`MonsterLevel/FloorMonsterLevel`、`PlannedKill*`和`CombatCellCount`等数值不能反向成为运行时合法MonsterActualLevel或强制生成数量权威。
- 有4个普通Dungeon包含合计12个`BossArenaCell`，见`C2A_4处普通地牢局部BossArena清单.csv`，它们不增加Castle数量。
- S10的136地牢静态预算9498杀包含20个可选Dungeon的1291杀；S11此前12480的“必经”合计误将可选Dungeon计入。参见`C2_C3_主线与可选内容预算纠偏_关键红项.csv`。

复现：`python verify_c2.py`，要求输出`P0_DIRECT_ORIGINAL_PASS`和`C2_STATIC_PASS`。这些均为**静态来源/配置校验**，不代表真实游戏已消费节拍/击杀数量。
