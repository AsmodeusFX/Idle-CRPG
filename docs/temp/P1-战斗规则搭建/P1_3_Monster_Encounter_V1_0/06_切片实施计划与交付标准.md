## E1｜基础怪物与房间

1. 将M01–M04映射已有MonsterDefinition/Policy/Encounter表；只增加缺失且经批准的最小字段。
2. 增加T01–T04的隔离测试fixture，任何真实奖励发放禁用或隔离。
3. 对AI延迟、队员入场展开、近战容量、远程最近目标进行可观察测试。
4. 使用原有怪物/占位模型展示各类行为；不阻塞于四套全新美术素材。
5. 在每一原型完成后跑现有回归，禁止集中到最后才发现TargetLock回归。

**退出门槛：** E1相关AI01–AI08与R01/R02/R05/R06有可验证结果；T01–T04正确构造；编译/测试执行报告诚实标注；若技能/画面依赖缺失需列BLOCKED。

## E2｜范围法师与猎手

1. T04-C使用现有AOE Effect与攻击合法性验证M05，不新增第9个基础房间。
2. M06使用显式后排优先策略，且不能改变M02普通目标优先。
3. 测试现有嘲讽强制锁定和受击退让版本；未就绪的另报阻塞或经用户专项审批。
4. 不引入真实碰撞或复杂寻路；冲刺只在现有Skill/Move合法支持情况下实施。

**退出门槛：** AI08–AI10与R03/R04/R07/R08，以及T04-C/T05有分项实际证据。

## E3｜召唤巫师、支援、Boss接口

1. M07最大存活数验证；召唤单位是现有战斗实体，生命/目标/死亡完全复用。
2. 召唤来源与奖励资格由现有事实链支持；无法明确防刷策略时**先问用户**，不得自行归零或重复发奖。
3. M08施加带来源与寿命的Buff；检查来源死亡、出范围与不同效果生命周期。
4. T08仅利用已存在Boss或隔离代理验证普通索敌与技能目标差异；无真实Boss则报告BLOCKED。
5. 房间清理与召唤者死亡关系用当前Encounter合同，不自行实现复杂的多波次导演。

**退出门槛：** AI11–AI18、R08–R10与T06–T08分项验证；出现反复掉落/无限触发必须FAIL而不是调数值掩盖。

## 交付前不得绕过的冲突审批

- AI延迟与用户实测散开方案：保留；发现与新房间定义冲突先提出最小替代。
- 受击退让：先读取最近代码变更及其验收；**避免重复实现**。
- 正式怪物奖励资格、召唤怪是否掉落及是否产生尸体：现有合同没有明确答案则提审批。
- 多人房间完成条件、召唤者死亡后仆从处理：按当前系统，冲突提审批。
- Boss TargetPolicy扩展或新增技能Effect：需专项批准。
- 独立护甲专项/P0-1未落地：所有调平报告注明当前使用的实际护甲版本。
