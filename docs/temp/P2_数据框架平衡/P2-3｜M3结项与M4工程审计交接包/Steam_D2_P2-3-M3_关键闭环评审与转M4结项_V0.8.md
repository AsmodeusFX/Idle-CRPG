# Steam D2《暗黑放置》｜P2-3-M3 关键闭环评审与转M4结项 V0.8

> 日期：2026-10-25
> 结论：**PASS_WITH_OPEN_ITEMS — 对进入 P2-3-M4 只读工程差异审计放行；不代表具体游戏数值、Lmin安全、十小时实机通关或P2-4编码需求已全部批准。**
> 范围：刻意结束无实际工程模型支撑的进一步细粒度脑内推演。此版是**M3的阶段出入口评审**，不修改《新版产品设计纲要 V1.2》的已确认产品规则。

## 1. 为什么此时允许 M3 收尾

P2-3-M3 的任务应是验证框架能否形成合理、可实现的成长循环，发现开发前需要解决的上游结构问题；而不是在真实新工程尚未搭建时就锁定最终经济、全部技能表现和完美保底机制。

已验证的**方向性结论**：

| 关键链路 | 可行性判断 | 当前证据与局限 |
|---|---|---|
| 公共XP → 玩家指定英雄升级 → 确定性AR/DR增长 | **设计逻辑成立** | V0.3、V0.7代理模型；取消等级差衰减后无“等级高于怪物而XP自动归零”的硬死锁；未实机 |
| 所有上阵英雄满足AR/DR门槛 → 花KP开放更高怪级 | **存在可校准、可逐档达到的方案** | V0.3、V0.7；无需依赖稀有装备或特定星图路线；评级准入不保证实际胜率 |
| 同级角色基础ATK/HP + 装备效率强化 → 战斗、掉落、收益 | **可构建合理代理模型** | V0.4指出强度还依赖技能解锁、房间人数及HP承伤；后续必须实装后验证 |
| 挂机积累 → 玩家集中消费 → 更高档生产 | **核心经济循环成立** | V0.5表明主动消费显著驱动增量，纯挂机不自动增长战力；产消价格与速度仍待配置 |
| 四章首轮 → 重生 → 账户永久成就成长 | **结构上成立** | V1.2已界定Run/Account边界；成就点和商店详细设计后置，不在M3阻塞 |
| 星图支撑长期金币消费 | **内容空间存在，实际购买容量未定** | V0.6跨系统强化盘点 + V0.7 10小时/约75次购买代理预算；不是75个正式节点 |
| 首轮四章目标时长 | **可以数学校准，尚未证明实机时间** | V0.7的10小时是工作假设，6/14小时敏感性对照；成功击杀速度为外生参数 |

## 2. 未通过项：不要为了收尾而假装解决

### O-01 / P0：KP 提高 Lmin 后可能断供

- V0.4 在极端孤狼/低技能情境中发现：区间由 `[1,4]` 改为 `[4,4]` 后，代理模型可出现零击杀、零XP、零KP。
- V0.6 发现：禁止 `[Lmax,Lmax]`、使 `Lmin≤Lmax−1`，配合较严格的自然AR/DR准入，**可以降低但不能保证消除**断供；极端怪物压力可使 `[3,4]` 同样断供。
- **本轮不拍板最终规则。** 建议把上述两项作为 M4 的候选需求接口，并把“所有合法队伍在允许的永久KP变更后仍有可靠成长资源通路”列为 P2-4 上线前的硬验收。
- 如果工程阶段暂无法验证恢复路径：应先把 Lmin 购买保持为**待验收/不开放给真实玩家**的功能，不能用“已满足攻击防御等级”宣称安全。是否增加紧急恢复、最低收益等机制须回到用户关键裁决，禁止执行AI自作决定。

### O-02 / P1：真实战斗成功击杀速度

V0.7设定的有效击杀率变化未由Godot的实际新版4技能+职业特性、移动、房间、多人压力、Boss、失败重试实现。M4必须确认实用可观察入口以及升级后所需的战斗模型改造点。

### O-03 / P1：XP、KP、金币、装备、星图的长期经济预算

已获得收入—点击容量的量级与反例，**没有**获得正式价格、掉率和节点拓扑。M4应找清相关代码所有权、配置入口与测试能力；这些内容在P2-4内容与数值开发中填充，不能把 V0.5 的10商品星图或 V0.7 的2.7成本系数写成正式配置。

### O-04 / P1：Run与Account存档分层、新旧工程链路

V1.2约定本轮XP/装备/KP/星图/地图重置，账号成就/职业/永久商品保留；工程入口、已有存档兼容和新账号/本轮状态的权威归属必须经M4现场审计。

### O-05 / P2：详细内容与UX

五职业完整技能小树、卷轴药剂、全星图节点、成就购物清单、4章怪物模板和UI精细队列排序均后置。已确认：英雄升级、KP消费、城堡命令不能自动合并；待替换装备超过4件时建议以一键批量换装合并，并展示英雄及部位。上述建议/阈值由最新用户反馈支持，工程实现仍待授权。

## 3. 给后续数值设计保留的最小暂用参照

- 单轮首四章暂取 **10小时**；对照6小时、14小时。明确区分挂机有效时间、在线交互时间、离线结算时间。
- 代理模型的章末检查点为约1.5/3.6/6.3/10小时，Lmax示意4/6/8/10，星图购买示意累计21/37/53/75。**全是[H]参考量级，不是正式指标。**
- 经验按击杀怪级全额入公共XP，英雄由玩家主动升级；自然AR/DR应基本满足下一档准入。自然ATK/HP基础值及装备强化的详细权重后续联立验证。
- Lmax与Lmin两类KP购买具有不同风险；不允许在配置中无审核统一套一份安全公式。

## 4. M3 的完成判定及 M4准入

**M3 = PASS_WITH_OPEN_ITEMS（策划可行性论证层级）**：已清理上游随机装备依赖、自动等级成长、经验衰减断链、缺重生终点等结构冲突，并保留可构造的风险反例。现阶段没有必要继续用纯离线脚本反复调节缺少工程支撑的参数。

**准许进入 M4：READ_ONLY_RECON。** 允许阅读真实最新工程、配置与测试设施，按新版设计逐项给出保留/修改/新增/迁移/不可观察清单。**不授权P2-4编码**；M3的未关闭项作为P2-4相关工作包的设计安全条件。

M4完成定义：新版设计 vs 最新工程差异矩阵、状态所有权与迁移方案、关键日志/模拟入口、依赖关系和初步工作包；据此进入M5设计与实施计划，交用户审批。
