## C1-A-1｜16固定技能＋四T

- 每职业S1～S4四个合法定义，四职业16个固定SkillId均能完整加载；S1开局已学且洗点后保底；S2/S3/S4未学不得出手，学习后由自动AI合理触发，效果可观察。
- BAR：重击、旋风斩多段但有界、战吼攻势/护队、先祖援军有限召唤归属；RAN：单箭、扇形分布多重箭、锁定追踪导引箭、有死亡/接敌行为的女武神；SOR：火球小范围爆发、冰霜新星减速、有限链式闪电、有前摇落点的陨星；PAL：圣击、盾击、祈祷主动治疗脉冲、祝福之锤有界旋转判定；T持续光环的守护/进攻互斥且同时间一形态。
- 每种技能区分合法/非法目标、单体/多怪、技能未学/已学、CD、伤害/治疗/Buff来源、快照读档、跨房及局部洗点的撤销/停止；不新增法力/怒气等资源条，或暗改Armor伤害权威。
- 共用ClassId资格由星图节点测试前置或QA fixture提供；**不得以C1A为由上线31星图**。
- 需要可观察的UI/UE证据（角色固定4卡+T、已学/待学、互斥和天赋洗点，战斗实际动画/日志，不只控件存在）。

## C1-A-2｜98节点

- 精确分布：BAR25、RAN25、SOR24、PAL24；每节点ID唯一，配置消费路径真实，Rank/前置/互斥/点数守恒和局部洗点/读档负向用例齐备。
- C0仅给出总分类：REUSE15 / MODIFY29 / NEW_EFFECT29 / DESIGN_DECISION25。**不得把总分类强行指定给具体节点**；以工程当前只读行级CSV重新强键核对，列出状态和所需Effect，并报告逐行进度。
- 原文`DESIGN_DECISION25`是25个**需细化/权衡的节点类别**，并非已证明25个完全无法实现；工程应按影响大小分类：合法参数H与显而易见的接口差异可自行QA落地，核心玩法身份/互斥/资源/控制时长的重大新取舍必须明确提报设计Owner与用户裁决。不得默认空效果或伪造成功。
- 触发引擎应考虑触发时点、击中/目标重复资格、Proc上限、ICD、召唤归属、目标评分、存档/洗点失效；特殊技能有可复现Seed和行为日志，四同职不无限叠层。
- S07 8套自然净24点合法路径跑通并产生路线身份差异，不能由QA强制解锁已互斥路径来冒充合法构筑。G03每人+2可作为隔离候选输入观察，但不影响24点基本验收，也不进入正式星图商品。
