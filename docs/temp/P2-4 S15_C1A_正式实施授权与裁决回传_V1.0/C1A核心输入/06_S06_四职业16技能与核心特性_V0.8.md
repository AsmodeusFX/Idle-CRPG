## 3. 选择取舍与非目标

### BAR｜旋风、战吼与先祖

- **首轮保留先祖援军**[P]，因为重构后M2已有野蛮人的先祖召唤示例；它提供与野蛮人近战联动的长CD高光，但不得把有界召唤物误写成多一个永久队友。
- S3战吼按天赋分支**攻势号令**或**有限嘲讽救场**；攻守不同，不是仅把ATK数字换成DR数字。
- T不是怒气条或每满X层后统一Buff；A在持续近战中强化旋风/攻势号令，B在合法友军承压时强化战吼/先祖护队。

### RAN｜经典投射物三件套

- 选定**多重箭、导引箭、女武神**作为首轮三项可学习技能[P]，换下V0.7连射、猎物标记、箭雨。后者转入未来内容池，不额外新增技能槽。
- 纯1D逻辑＋2D扇面表现：屏幕看到的每一支箭**不等于**额外真实命中。多重箭按合法不同敌人分配；只有特定节点声明穿透/有限同目标二次伤害资格。
- 追踪箭先锁合法目标；目标失效按现有投射物合同处理，不擅自假设立即换锁。女武神必须是真实可死亡、跨房保留状态、占合法接敌容量的召唤物。
- T两方向是**清群目标分配**与**精英单体追踪**，不是蓄满专注给短时增伤。

### SOR｜独立元素流派

- S1火球由第一分钟就承担**范围爆裂识别点**；其基础范围和伤害显著低于长CD陨星，不能因为是普攻而吞掉S2/S3价值。
- T禁止规定“火→冰→雷必须轮换才能获得多数收益”。可选**火焰专精：火球＋陨星**，或者**霜雷织网：新星减速＋连锁闪电**。
- 冰控场默认减速不冻结，雷链不会重复跳同一个已用目标，陨星前摇允许敌人走位造成空放；没有新增第六元素或奥术伤害。

### PAL｜恢复持续光环身份

- 将**持续光环置于T特性树**，而不是恢复旧P1可装备多个光环的主动技能槽。购买按ClassId的星图资格后，英雄仍需投资T01才生效；未投资前不存在职业光环自动馈赠。
- T01[候选]产生可观察的基础小范围护佑光环；后续**T03守护祈祷 / T04狂热进攻互斥**，它们是**同一光环的形态替换**，不是叠加两个主动光环。一个圣骑士不能以免费局部洗点保留旧光环残留。
- S3“祈祷”是AI触发的单次治疗脉冲，不是第二个持续光环；与T祈祷光环有不同来源与周期语义。S4祝福之锤在1D实际命中、2D环绕展示，不能通过动画穿墙伤害。
- 同队两个圣骑士可以分别选不同T路线；不同光环在同一合法目标上的共存规则由各自Buff协议控制，**同名多来源如何择强是[P]候选，须在正式内容规格验证后落配置**。召唤物不得通过主人继承＋直接受光环重复吃两遍。

## 4. 统一实现与设计安全边界

1. 本轮不新增法力、怒气、专注、祷告值等玩家资源条，也不恢复旧技能装配槽。
2. 生命、伤害、Buff/Trigger/Projectile/Summon统一走已确认战斗系统；合法目标按当前房间、射程和接敌容量选，不自动远距离救场。
3. 每次多段伤害结算可有独立DamageInstance，但Proc资格与每技能命中/链上限分开；不把真实多段伤害伪造成一次命中，也不能无限派生。
4. 同职业重复实例的投射物、Buff、光环和召唤物按**HeroInstanceId**归属，不能用ClassId合并；职业星图只共享学习资格。
5. 具体CD/倍率/范围/强度/上限均保持[H/O]，S04假设英雄Lv和10小时进度不构成硬等级门槛。

## 5. 需要实际观察的身份镜头（[V]待验收）

- BAR：普通怪群里旋风持续多段；队友被围，战吼嘲讽只有近距敌人转火；远处怪物不“被吸来”。
- RAN：同屏不同敌人被扇面箭覆盖；Boss场导引箭合法跟踪；女武神在队伍前方独立承压。
- SOR：火球早期小范围爆裂；减速敌人形成雷链；火专精的陨星和霜雷线的控场表现不同。
- PAL：不开T光环和开T后明显不同；守护光环在跨房、死亡、离场、局部洗点后正确消失；狂热光环与祝福之锤的持续配合可见。
