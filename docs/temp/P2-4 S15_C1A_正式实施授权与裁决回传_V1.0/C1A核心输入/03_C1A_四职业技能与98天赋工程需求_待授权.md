## C1-A-2：98天赋和底层Effect支持
工程报告分布`REAL_REUSE15/MODIFY29/NEW_EFFECT29/DESIGN_DECISION25`仅是**全表合计**，本包逐节点CSV故意将工程行级判定留空；执行AI必须附原`effect_coverage_engine_complete.csv`并与节点ID匹配后实施，不得假造逐行分类。

优先在已有框架扩：
1. `trigger / proc_limit / proc_icd`或等价消费者：合法触发条件、每目标/每事件封顶、冷却与源归属、读档重置；不许无限召援或无限资源循环。
2. 目标评分与索敌：精英/威胁/覆盖选择，确定性Tie-break、死亡刷新；不越过玩家手动卷轴策略。
3. 职业核心T的可观察Buff/召唤/互斥路径；特性资格`ClassId`共享、实际投入`HeroInstanceId`独立。
4. 确定性修饰器：atk/hp/AR/DR、暴击、阻挡等需合法既有属性消费，不复活Armor双权威。
5. 需设计Owner裁决的25项：由执行AI按ID、设计文案、缺哪个数值/目标/互斥/触发条件列**设计影响清单**，不能自行将关键玩家体验改成泛化伤害百分比。
