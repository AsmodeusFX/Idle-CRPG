## 2. 第一批预留的接口（避免返工）

- **WP1**：每个英雄实例ID与Account/Run状态所有权；Run预留装备绑定、消耗品库存和星图当前状态，Account预留成就事实、AP余额/永久解锁字段，但不可擅自发放。
- **WP2**：AR/DR和基础ATK/HP的Modifier/快照消费接口，允许后续装备、星图、Buff合法叠加；不把装备改为升档的唯一通路。
- **WP3**：KP通用账本与可扩展购买类型接口；当前只面向玩家开放Lmax购买。掉率、怪数等可以后来增补；Lmin风险钩子可以有，但不可公开执行。
- **WP0及每包UI**：统一截图/烟测/历史归档保护。卷轴下沿横条、药剂右下四槽先做稳定结构，不在第一批虚构消耗品成功使用记录。
