全章结构与解锁关系

  1. 群魔堡垒 → 郊外大草原 → 绝望平原 → 神罚之城 → 火焰之河与混沌避难所。大地图只负责行走与解锁，不刷怪。
  2. 绝望平原 Castle 的最终 Boss 是 衣卒尔；火焰之河的终局 Castle 包含五处封印、三组封印守卫与 迪亚波罗。
  3. 地狱熔炉位于火焰之河的下方岔路，解锁后仍要玩家手动批准进入，支线 Castle 也需再次批准。此支线不影响进入混沌避难所。
  4. 四条主线区域仅通过配置的石桥 / 城门 Gate 连通，其他毗邻颜色不同的地块视为被城墙、断崖、熔流阻断。
  5. Castle 六阶段深地牢属于本游戏改造；官方 D2 Act 4 没有这些额外原创地下城，文件已清楚标注来源属性。
