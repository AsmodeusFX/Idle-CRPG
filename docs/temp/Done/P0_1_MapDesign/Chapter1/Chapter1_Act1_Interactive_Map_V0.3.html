设计说明：这版与原 D2 的对应关系

  • 罗格营地只有一格：位于接近图形中心的位置，唯一直接出口就是鲜血荒地。
  • 前两个区域不改名：鲜血荒地 → 冰冷之原；营地到鲜血荒地存在真实的相邻关口。
  • 血乌保留单独区域：埋骨之地是冰冷之原开放的分支；不强制阻断去石块旷野的主线。
  • 石块旷野 → 黑暗森林的「地底通道」：地图上是唯一可通过的山脉关口，并在石块旷野设置对应地牢。
  • 大教堂是终局 Castle：攻入大教堂后，Castle 内部继续深入名为「地下墓穴」的深层地牢，最深处为安达利尔。
  • 区域 Castle 允许适配新增：除遗忘高塔、大教堂等原典地标外，其他 Castle 多为游戏系统服务的新增据点，已明确标注，不冒充 D2 原始设定。

尚未批准 / 下一轮只需确认的关键点

  • 地图 8×8：这是第一版高密度测试方案，不是锁死所有章节的格子规格。
  • 埋骨之地主线分岔：建议按 D2 处理为可选优先级，清冰冷之原 Castle 即可同时开放埋骨之地与石块旷野。
  • 崔斯特姆的开启时机：为了不造成“需要先进入黑暗森林拿伊尼弗斯之树，却又必须先通关石块旷野全部地牢”的死锁，草案暂将崔斯特姆视作可进入的常规地牢。若保留原 D2 回访解谜，则应改成不计入前置必清数的特殊支线，待讨论。
  • 新增地牢数量：D2 原典部分区域并没有足够多的独立地牢入口，图中明确用新增副本补足；这些是策划占位名，不是已确定正式内容。
  • 地牢数量≠地牢层数：洞穴 2 层、遗忘高塔 5 层、地下墓穴 4 层均以一处大地图入口计数，多层归属同一地下城。
