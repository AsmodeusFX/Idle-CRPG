全章结构与解锁关系

  1. 库拉斯海港 → 蜘蛛森林 → 剥皮丛林 → 下层库拉斯 → 库拉斯商场 → 上层库拉斯 → 库拉斯堤道 → 崔凡克。
  2. 庞大湿地在蜘蛛森林 Castle 后开放；古神庙群在库拉斯商场 Castle 后开放。两条支线均必须玩家批准，且不阻断主线。
  3. 克林姆之眼（蜘蛛洞窟）、之脑（剥皮地牢）、之心（库拉斯下水道）均放在主线必清地牢；议会连枷与强制球体放在崔凡克 Castle 内，绝不形成前置死锁。
  4. 终局 Castle 内先打议会，再深入 憎恨囚牢 1–3 层，最后对战墨菲斯托。
