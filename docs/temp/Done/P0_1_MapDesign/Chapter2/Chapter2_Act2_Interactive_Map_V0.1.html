全章结构与解锁关系

  1. 鲁·高因 → 碎石荒地 → 干燥高地 → 遥远绿洲 → 遗失城市。
  2. 遗失城市 Castle 征服后，群蛇峡谷与皇宫／神秘庇护所同时解锁；皇宫从鲁·高因的南侧入口进入。
  3. 两条主线 Castle 都被批准并征服后，从神秘庇护所的传送门进入术士峡谷。
  4. 七座古墓：六座假墓普通地牢 + 一座真正古墓 Castle；打败都瑞尔通关本章。
  5. 鲁·高因下水道初始可见，古代通道在遗失城市后出现；二者需要分别批准，未清不阻断主线。
