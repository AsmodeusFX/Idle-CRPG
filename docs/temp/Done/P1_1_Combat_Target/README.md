## 明确限制

- 新规则只替换/扩展**怪物普通目标选择和近战接敌分配**的合同，不重做伤害、装备、宝箱、任务、世界地图、挂机切区系统。
- **不使用 MMO 伤害/治疗仇恨累计表，不使用接敌压力公式。**
- **接敌容量不等于受攻击硬上限**；远程普通攻击不占容量，后排默认为0仍可被任意多只近战怪攻击。
- **不引入战斗单位之间的物理挤压/刚体碰撞**；不破坏现有技能范围与投射物连续碰撞机制。
- 详细实现以运行中代码为依据并受项目现有 `Confirmed` 文档约束；历史资料可能与最新的多角色设计冲突，必须先上报。
