# 02｜五职业首批代表技能：垂直切片规格 V0.1

> **整体为 R：推荐设计，不是已批准生产技能清单。** 各职业三系方向来自前序讨论；此处17个候选技能专门覆盖跨职业规则 G01–G06。伤害、CD、施法时间、等级门槛、点数、目标数、射程、场景节点、表现与资源仍 T。
>
> **工程落地原则：优先做可测试行为，不强求第一批就开放全部技能。** 如果现有实现不支持某个技能必要 Effect/TargetPolicy，不允许新造平行战斗系统；先向用户确认扩展方案。

## 2. 共用技能行为模板（R）

每个主动技能**建议设计清单**：

- 技能释放资格：已学习、已装备到有效技能槽、CD Ready、行动状态可用、目标与射程合法；光环激活和维持采用与普通主动技能不同的持续效果语义（具体需审计）。
- 目标：主目标 `TargetLock` 与临时技能目标分离。技能自主选范围中心/多个目标**不默认改变普攻锁定**。
- 动作：`Windup→Commit→Recovery`，CD 在 Commit 起算；控制打断资格依据 Runtime，不在 AI 里手动打断。
- Effect：伤害/治疗/ApplyBuff/召唤/投射物等全部通过既有 Effect 语义；缺少合法 Effect 类型需先审计扩展点。
- 事件资格：区分 Cast、直接 Hit、伤害、击杀、周期 Tick、Proc 源；每个技能有合法的 Proc 来源语义和同目标命中规则。
- 实机诊断：事件链根 ID、目标、技能动作、伤害与 Effect 来源、Buff 来源与注销原因、召唤主人 ID。

## 3. 第一阶段 A：先把普通伤害和弹道跑通（R）

### BAR_BASH｜野蛮人·重击

- **角色定位：** 单体近战基线，无自带嘲讽效果。
- **触发：** 有合法近战目标、CD可用；未进入可用射程时按既有射程驱动 AI 接近。
- **Commit：** 对合法目标申请一次直接物理伤害；是否附带短硬直由独立 Effect/强化节点决定，默认基础版不附加。
- **验证：** 消耗动作时间，暴击/格挡/护甲按统一 DMG；不因“重击”二字无限提升接敌容量。

### PAL_SMITE｜圣骑士·盾击

- **角色定位：** 近战单体，技能强化可附短控制；并不是被动常驻拦截。
- **触发：** 有效近战目标，处于合法施法状态。
- **Commit：** 直接物理伤害；附加的眩晕/硬直由可配置 Effect 管理，控制失败不自动否定伤害。
- **验证：** 法师被突破前排时，盾击不能无距离跳跃救场；后续如加入守护冲锋，须是独立技能/强化。

### SOR_FIREBALL｜法师·火球

- **角色定位：** 基础范围法术。
- **触发：** 合法敌人；优先选择能产生合理范围收益的命中目标，目标评分细则 TBD。
- **Commit：** 产生既有合法投射物；其有效命中触发一次火焰范围伤害 Effect；火伤**本身不自动点燃**。
- **验证：** 命中范围内多个目标时每目标统一 DamageInstance；已确认事件资格限制；技能目标失效时按既有投射物行为审核，不假设必追踪。
- **不在首批强制加入：** 击杀二次爆炸，需独立强化节点及 G06 链资格。

### RAN_MULTISHOT｜游侠·多重箭

- **角色定位：** **纯弓箭**物理多弹道；不引入标枪/近战武器。
- **触发：** 有合法远程目标且当前装备为游侠允许的弓箭类武器；扇形有效目标与射击方向的选择细则 TBD。
- **Commit：** 一次技能生成多枚箭矢，各自可能命中多个不同敌人，合法命中照常结算伤害。
- **边界：** 同次释放多箭命中同一目标的有效伤害资格需单独设计，不允许因为屏幕投射物重叠而无限触发；Proc 资格与真实伤害次数是两层规则。
- **验证：** 纯1D逻辑战场＋二维表现不能把视觉扇形直接当成已具备真实2D碰撞。先审计已有投射物分发模型，再批准表达方式。

## 4. 第二阶段 B：Buff/状态、基础控制与召唤（R）

### BAR_TAUNT｜野蛮人·嘲讽

- **触发条件建议：** 被多个敌人近战威胁的队友在合法范围内、技能Ready；允许针对一般合法敌人使用。
- **Commit：** 对有限目标施加持续 `Forced` 或项目现有等价锁定效果；允许暂时超过普通接敌容量，不增设仇恨计分表。
- **失效：** 强制锁定到期、目标死/失效、特殊免疫等在安全行动边界恢复原选敌策略。
- **验收：** 被嘲讽怪物可继续被已有房间/距离/控制规则约束；不得跨图“瞬间吸怪”。

### PAL_PRAYER｜圣骑士·祈祷光环

- **定位：** 持续地牢的**稳定续航**，不是强烈的战斗急救技能。
- **槽规则：** 仅在装备主动技能槽时维持。与其他不同光环可以同时生效。
- **效果：** 对合法范围内友军的 HP 提供周期性 Heal Effect；周期/范围/数值T。
- **验收：** 进入/离开范围、生死变动、卸槽（若已获授权）、回城过渡不造成重叠治疗或 Buff 残留；小队不因此获得无限战中治疗循环。

### PAL_FANATICISM｜圣骑士·狂热光环

- **槽规则：** 与祈祷同时装备并维持时各占槽，效果同时存在。
- **效果：** 对符合资格的友军/召唤物提供攻速与限定输出方面 Modifier；具体属性和幅度 T，不能凭“狂热”名称新增乘区。
- **验收：** 骷髅从光环进入到离开，攻速只出现一次正确增减；光环退出后完全撤销；主人的临时光环不经继承再重复进入召唤属性。

### SOR_FROST_NOVA｜法师·冰霜新星

- **定位：** 近身敌群的防御性减速，而不是永久冻结。
- **触发：** 当前范围存在可观测近战威胁/一定数量近敌；优先级高但不能打断不可取消 Windup/Commit。
- **Commit：** 周围范围冰霜伤害（如有）＋减速 Buff；**默认不自动冻结**；冻结需独立技能强化/Effect。
- **验收：** 与普攻/投射物命中资格不同；怪物控制持续时间/免疫按合法 Buff 处理；远程受击退让仍由通用 AI 负责。

### NEC_RAISE_SKELETON｜死灵·召唤骷髅

- **触发：** 已装备，存在未达到上限的召唤名额与合法召唤位置；**不需要尸体**。
- **Commit：** 生成已批准的独立战斗实体（近战骷髅，基础属性、容量、AI）；数量、召唤间隔和属性继承待测。
- **持续：** 召唤物跨房间保留实际 HP/数量；死亡及时释放全部目标引用/接敌容量。
- **奖励：** 骷髅自己死亡不成为刷经验/尸体的合法来源；骷髅击杀敌人按队伍经验规则结算。

### NEC_AMPLIFY_DAMAGE｜死灵·伤害加深

- **触发：** 有尚未处于合适有效状态的敌人；无须在每 Tick 反复刷新。
- **Commit：** 施加物理易伤类诅咒，贡献进入**既有 `M_vulnerable`**（具体分类以旧公式审核）。
- **共存：** 可与降低抵抗、衰老等不同诅咒同目标共存；同一诅咒重复施加走已批准策略。
- **验收：** 物理伤害提高的数值不能重复进入 `M_general` 和 `M_vulnerable`；来源移除时完全撤销。

### RAN_GUIDED_ARROW｜游侠·导引箭

- **触发：** 有合法射程内目标；优先处理移动怪或残局单目标；具体候选排序 T。
- **Commit：** 生成跟踪已锁定合法目标的弓箭投射物；若目标死亡、离房或不可攻击，采用现有投射物目标失效合同（T，不能自主决定“自动重锁”）。
- **验证：** 不产生临时近战寻路；跟踪移动只属于弹道而非敌人主索敌改变。

## 5. 第三阶段 C：特殊队伍交互与链式机制（R）

### BAR_WHIRLWIND｜野蛮人·旋风斩

- 有界的持续攻击动作/移动窗口，多次合法物理伤害；近战移动合法性使用原 Runtime；不新增真实刚体碰撞。
- 各次 Hit 可正常造成伤害，装备 Proc 独立限制；动作中受击与退让处理遵守原不可中断边界；旋风**不天然增加接敌容量**。

### PAL_CONVICTION｜圣骑士·信念光环

- 主动持续光环，独立占槽；可以与祈祷、狂热同时维持。
- 对范围内合法敌人添加元素抗性降低贡献，且全元素减抗按统一抗性解析处理（负抗下限 T）；不额外创造“信念乘区”。
- 与死灵降低抵抗共存时都贡献有效抗性，不应重复计算为两层单独增伤。

### SOR_CHAIN_LIGHTNING｜法师·连锁闪电

- 对一个合法初始目标施加闪电伤害，然后在有限目标间跳跃；已被本次链命中的目标是否可再次被命中：T，建议按单独技能规则。
- 每次合法命中通过统一 DMG；连锁跳数/衰减与 Proc 源资格分别配置，不能无限弹射。

### NEC_LOWER_RESIST｜死灵·降低抵抗

- 敌方诅咒，降低四元素抗性的有效值；可以和伤害加深共存；同一诅咒重复刷新/替换不无限叠层。
- 若同场有信念光环，合并到有效抗性解析并遵守唯一截断时序，不额外新增乘区。

### NEC_CORPSE_EXPLOSION｜死灵·尸体爆炸

- 只有合法、尚未被消费的尸体才能释放；选择与目标区域相关的可用尸体记录。
- Commit 取得一次性的尸体消费权；成功才向附近合法怪物产生范围伤害请求；失败则按已批准的技能失败/扣CD规则处理（**T，不能偷定**）。
- **尸体强度、物理/火混合比例、Boss尸体等尚未锁定**；首批仅在隔离测试配置中使用明确符合法定五伤害类型的占位值。
- 原始尸爆本身不自动继续尸爆；“连环尸爆”作为后续独立机制强化节点，需要 G06 合法链资格。奖励/死亡事实只结算一次。

### RAN_VALKYRIE｜游侠·女武神

- 主动召唤，占技能槽；少量高质量的独立可攻击召唤单位，属性/接敌容量与死灵骷髅有所区分。
- 召唤物跨房间保留状态；遵循普通近战锁定与容量，死亡/离场释放锁定，无原地自动复活绕过 CD。
- 女武神自身可使用近战武器是**召唤单位行为**，不改变“游侠本人仅使用弓箭”的正式职业规则。

## 6. 五职业实际可玩的首批配置原则

- **不能用一次解锁全技能槽的测试开关改写正式星图成长。** 压力测试允许在测试专用装载上下文注入多槽条件，生产仍初始1槽、最大5槽。
- 若一名英雄初始唯一技能不在本次清单中（例如法师火弹），先核查实际角色创建与初始已学技能；新增或替换初始技能、是否免费赠送是单独审批项。
- 每职业三系**只是职业长期技能池**，不是“必须首批做齐三系”。首批验证5种职业不同机制的代表技能，余下内容在原型验收后逐步扩展。
- **近期已引入的敌人 AI 延迟、入场散开和远程受近战伤害退让**必须保持与技能动作生命周期兼容；远程施法/炮轰在不可取消阶段不因受击回调直接中断。
- 新增技能不得自行决定物理减法护甲、魔法伤害类型、DOT每Tick触发资格、未签署的技能点成本或装备词缀概率。

## 7. 阶段准出

**A 准出：** 四类基础技能可在纯 Core 伤害/弹道规范下重放，同样种子伤害/目标一致；投射物与视觉一致。  
**B 准出：** 两个并存的圣骑士光环、1个诅咒、基础骷髅召唤、嘲讽、冰霜状态均正常应用/清理，无同名重复收益。  
**C 准出：** 多光环+多诅咒+减抗、两个召唤来源、尸体唯一消费、连锁弹射与 Proc 上限在无头测试与 Godot Mini 模式验收均通过。  
所有准出都以前置审计与必要用户审批为条件，不默认本包已发出编码授权。
