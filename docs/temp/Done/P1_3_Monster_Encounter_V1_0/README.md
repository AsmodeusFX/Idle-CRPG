## 最重要的边界

- **不要重写已存在 `MonsterPolicy` / `Encounter` / `ActionRequest` / `Skill + Effect + Buff` / 战斗事件队列。** 与现行接口冲突先上报审批。
- **保留近期真实工程优化**：敌人AI启动延迟、小队入场散开、入门边界约束；远程受近战命中退让以“已下发 Claude Code、实际落地状态待核实”处理。
- **最新工程规则优先于历史文档中“怪物看见首名英雄便立即启动”的描述。** AI延迟时长和队员散开长度必须读取现有配置，严禁本包静默写死。
- **不使用真实单位物理推挤**；不能因此破坏已有投射物、墙体、攻击距离、持续碰撞检测。
- **不在本包制作五章正式怪物投放/完整Boss、新掉落规则、大型怪物行为树、独立导航系统。** 这些属于后续Todo。
- **不擅自修改伤害公式。** 护甲从减法改为递减百分比是独立P0-1迁移事项，需要按当前项目状态和专门执行审批处理。
- **怪物配置中的数字与ID全部是TEST_ONLY候选，不是批准的平衡值。**
