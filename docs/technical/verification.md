## 2026-10-18 移动流畅性、镜头及状态存档

- 确认原型逻辑是固定 20 Hz 单机模拟，不涉及网络帧同步；原来直接绘制逻辑位置，60 FPS 窗口也呈现 20 Hz 的角色跳动。现在角色、怪物、室外位置与镜头跟随使用逐帧插值，逻辑碰撞和奖励仍在固定步内计算。
- 主线程不再执行常规存档的 JSON 编码与 Flush；只在关键状态变化后复制独立检查点，串行后台写入。无状态变化不会每 5 秒写盘。退出/重置等待任务完成，已通过后台任务与重置竞态检查。
- 正式存档不保留怪物交战现场，读档从进房节点重新开战，击杀即时经验和升级保留；允许重开再得击杀经验。物品和金币在清房、救援后走近拾取才入库，部分拾取后加载不会重复领取，旧版存档仍可读取。完整模型快照仅供内部确定性回归。
- 检查了镜头首帧位移与连续收敛；进房采用保留速度的临界阻尼中心/缩放过渡。HUD 限频、地图统治状态缓存，村庄缓存导航路径避免每步回头。
- 核心回归、Godot 冒烟和真实控件后台保存/重置、跨进程读取及实际窗口截图检查通过。
