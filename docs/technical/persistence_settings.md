## 自动保存与恢复

GM 发放的金币、每名上阵英雄的经验和对应成长按普通关键进度保存。无敌、怪物有效血量/攻击倍率、每房额外怪物数量属于临时会话参数，不进入 SessionSnapshot；读档恢复默认。已生成房间的数量仍按既有出生快照保存，参数重置不回滚已生成内容或资源。具体边界见 design/gm.md。

城堡挑战队列使用有序 `PendingCastles` 保存，按点击顺序恢复；兼容旧档的单目标 `PendingCastle`。当前已派遣城堡仍由世界目标与阶段保存，后续排队不会覆盖该目标。

正式运行使用 Godot `user://` 用户数据目录，Windows 通常为 `%APPDATA%/Godot/app_userdata/Idle-CRPG/`。`progress_v1.json` 是游戏进度，`settings.json` 是显示/音频偏好；不放在 config，不提交 Git。

正式存档采用关键状态驱动，不是逐帧或逐次命中保存。触发点为：开局选队、击杀即时获得经验/升级、刷怪加成命令（未来加点入口）、走近拾取金币/物品、房间事件领取、首次触门揭示/内容生成、展开新区域、切层/通关/占领、救援开始与完成、全灭返村、交易补给、安排城堡挑战。暂停、倍速、视图、设置面板、失焦也请求保存；正常退出等待最新状态落盘。普通移动、伤害、攻击冷却、交易/救援读条推进不触发写盘。

连续关键变动按 `autosave_min_seconds`（当前 0.5 秒）合并，后台已有任务时只保留最新待保存状态，不积压队列。取消原有每 5 秒无条件保存；CSV 的 `checkpoint_seconds` 暂留作兼容字段，不再用于周期写盘。界面显示的击杀经验立即实际到账，允许玩家关闭重开房间再次获得经验；此行为按用户要求不做防刷限制。

版本 2 保存固定队伍与成长属性、经验、金币、背包、刷怪加成、地牢各层拓扑/探索/清理与事件标志、待拾取战利品、世界统治进度、场景与行进目标、村庄流程和界面偏好。未清房战斗只保存出生模板（类型、等级、位置和生成加成）及进房小队节点；不保存怪物剩余血量、攻击计时与追击轨迹。战斗中读档恢复到进房位置和进房生命、清除攻击冷却，保留已经到账的等级/经验/属性，怪物重新开战；进房随机源也回退，使同次挑战的掉落随机序列稳定。清完房后保留尚未领取的掉落，领取标志和到账资源一起保存，已领取掉落不再写入文件；清理完的房间不保存怪物尸体。救援和清房后交互、室外路线仍可续接，不结算离线收益。`Capture()` 仅供内部确定性测试保留完整模型现场，正式保存统一使用 `CaptureProgress()`。

兼容版本 1 旧存档，首次读取沿用已有进度，不强制重置；转换为新档时，缺少出生模板的旧房间仅使用剩余活怪构建重开模板，避免重新创建已在旧版结算奖励的死怪。缺少进房记录的旧档采用房间中心和当前最大生命作为过渡节点。

版本 2 增补 Stars（稳定 ID/等级）、StarAttack/StarHp（上次已应用贡献）和星图视图 3；购买/编辑器发布定义后即时请求关键状态保存，金币和等级同快照。旧档缺字段按零星图处理，未知/重复/超等级/前置非法的记录拒绝恢复。恢复时只应用新旧贡献差量，避免已存聚合属性再次叠加；战斗检查点不回滚已购星图。确认重置清空星图进度；GM 菜单、编辑模式和未保存草稿不保存。

主线程复制不共享可变引用的精简检查点，后台单任务编码、写临时文件并 Flush，再原子替换主档、保留 `.bak`。后台完成后才确认已保存版本，失败保留脏状态并重试；暂停和面板操作也只安排任务。重置和退出先等待正在写入的任务，防止旧任务覆盖新世界/复活旧档。加载校验版本、资源引用、拓扑、数值、当前场景与目标、救援关系和路径。主档损坏时尝试有效备份并提示；恢复后首次保存不把坏主档覆盖到健康备份。主档和备份均无效时保留原文件，界面提示并等待玩家开始新远征。

## 设置与重置

右上角“设置”打开独立遮罩面板，打开期间暂停模拟，关闭后恢复玩家原有暂停状态。包含窗口尺寸预设（CSV 配置）、全屏、音乐与音效音量。拖动窗口尺寸会记录当前尺寸；从全屏退回窗口时延迟一帧应用尺寸。固定 1440×900 设计界面等比缩放，不裁切界面。

“重新开始世界远征”已移出主界面，设置内为“重置进度”。第一次点击弹出独立确认框，明确列出清除范围；取消不改进度。确认后清空主档及备份的游戏进度，返回开局选队；窗口和音量偏好保留。新远征立即写入新档。

## 音频

按用户授权复用 `E:/Git/Idle-Sword/idle-sword/Assets/Audio/` 的程序生成 WAV 占位音。来源记录在本项目 `Assets/Audio/README.md`。映射、单独增益与限频在 `config/audio/audio.csv`。

Music/SFX 分总线，音量 0 静音，再调高立即恢复。音乐循环设置完整起止帧；8 个音效播放器轮转，按真实播放时间限频。触发包括点击、设置面板、命中、击杀、升级、交易、地牢通关、复活与全灭。读档只建立音频状态基线，不补播历史声音。退出前停止音频并等待混音线程释放。

## 验证入口

- `dotnet run --project tests/IdleCrpg.Checks.csproj`：内部完整快照确定性回归，以及正式精简存档的房间重开、即时经验保留、清房后走近拾取、部分拾取读档不重复、旧档兼容、备份及重置检查。
- Godot `--headless -- --smoke-test`：真实控件设置、音频资源/循环、静音、取消和确认重置。
- Godot 先 `--headless -- --persistence-write`，退出后再 `--headless -- --persistence-read`：跨进程自动恢复验证。
- Godot `-- --smoke-test --display-smoke`：实际图形窗口验证尺寸、全屏及恢复窗口尺寸。
- Godot `-- --capture --capture-settings` / `--capture --capture-reset`：设置及确认框截图。

自动检查与截图使用忽略的 `artifacts/qa/` 专用存档，不加载或覆盖玩家 `user://` 进度。

## 镜头与寻路版本兼容

统治区门禁采用 `WorldSnapshot.AreaPartAccessVersion=1`。解锁由城堡通关集合与 CSV 前置关联实时推导，不单独保存可过期的解锁布尔值。旧档缺字段为 0：若当前处于新规则锁定统治区，保留等级、经验、背包、金币和通关历史，放弃本轮地牢，回初始村庄交易后按新规则冒险；若仅当前赶路目标或路线越界，则保留合法的已安排目标并重建路线，否则重新选择可用目标。新版本档拒绝越界目标和路线，旧探索历史不授予解锁权。

自然布局采用 `WorldSnapshot.LayoutVersion=1`。缺字段的旧 16 城堡方块地图先迁移：保留等级、经验、金币、背包、探索历史及仍有效的普通地牢通关记录；新辖区全部落入旧已占领格子时才继承占领，并继承辖区内新增地牢的完成标志，避免把旧 cN 编号错误套用到新位置。地图变更会放弃本轮地牢，转到可用村庄重新补给，不保留未拾取战利品和旧攻城排队；累计资源不会清空。当前点位锁定时回初始村庄。随后按新前置继续冒险。

编辑器内嵌运行通过 `Engine.IsEmbeddedInEditor()` 识别：尺寸与全屏控件禁用并显示说明，不调用原生窗口尺寸、居中或模式接口，编辑器视口变化不覆盖保存的独立窗口尺寸。独立运行仍可调整窗口并切换全屏。

存档新增房间 HalfWidth/HalfHeight、世界 PendingCastle 和 NavigationVersion。旧存档未包含尺寸时沿用旧版 3.5 半宽/半高；未包含导航版本（0）的赶路路径加载后按同一目标重建为细网格避障路径，新版本为 1。保留队伍、资源、房间内容及世界进度，不要求重置存档。排队的城堡挑战随快照恢复；颜色由统治区当前通关状态实时计算。
