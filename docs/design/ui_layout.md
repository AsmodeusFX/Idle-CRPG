# 主界面五区构图

设计尺寸仍为 1440×900，随窗口等比缩放。顶部功能标签为“游戏”“城堡”“星图”，右上角依次显示游戏名称、GM、设置、暂停；三个按钮统一为 80×36。GM 仍是所有调试入口。倍速位于游戏战斗视口左下角，仅在游戏页面有远征时显示。

游戏页面左侧中央为主要战斗视口，房间战斗镜头依照可用高度适配并完整入镜。城堡、星图和星图编辑器都使用顶部栏下方整个 1392×784 内容区，隐藏游戏页的货币、交互、小队状态和药剂区域。

城堡页左侧可滚动列出配置中的全部城堡名称与攻略状态：未解锁、地牢完成数、等待攻略、计划攻击、已占领，状态颜色与世界地图一致。右侧显示完整世界地图；点击列表定位并勾勒统治区，点击地图同步选中对应城堡。列表选择不直接发起挑战，攻城仍从游戏交互卡安排。地图点击命中直接使用与绘制一致的原点及格宽。星图和编辑器保留原有购买、缩放、字段编辑、草稿保护与 GM 入口。

右侧上方货币按首排三个、次排一个构图。当前首排为金币、杂物数量、当前经验；杂物是已有库存计数。次排保留成长点占位，显示“—”，不创建资源或消费规则。

右侧下方为滚动交互列表。功能排序约定为角色升级、穿戴装备、功能强化、挑战城堡，同类型按首次刷新时间排序；当前只投放第四类。每个满足门禁和普通地牢完成条件的未占领城堡拥有独立按钮，不受地图选择影响。按钮包含图标、名称、等级与描述；当前挑战免费，不显示消耗数量及资源图标。后续收费功能应同时显示消耗数量和资源类型图标。排队及执行中的卡片保留状态并禁用，通关占领后移除；刷新不改变仍存在卡片的先后顺序。按钮只调用 GameSession 命令。

左下角色区预留五个席位，每个已有角色显示占位图标、名称、等级、生命条、HP 和 ATK，空席显示占位。当前版本仍沿用三人开局，未扩展招募或阵容逻辑。右下药剂区仅展示四个占位槽，不生成可点击的强化或购买按钮。

开局选队放在右侧交互区，进入远征后隐藏。新增布局、占位图标、交互卡及刷新次序属于 UI 表现，不写入玩家成长数据。Godot 冒烟检查覆盖五区控件、三座城堡独立按钮、刷新顺序及点击排队；截图和检查只使用 artifacts/qa 专用存档。
