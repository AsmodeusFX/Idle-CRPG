# 主界面五区构图

2026-10-18章节版本覆盖以下旧左右布局描述：城堡页地图在左、详情和城堡清单在右；地图上方为难度下拉与五章页签。未解锁入口置灰并提示原因；菜单只查看地图，不改变当前远征。打开城堡页默认选择当前难度/章节/玩家格。各章按独立尺寸适配，详见 [章节地图](world_chapters.md)。

设计尺寸仍为 1440×900，随窗口等比缩放。顶部功能标签为“游戏”“城堡”“星图”，右上角依次显示游戏名称、GM、设置、暂停；三个按钮统一为 80×36。GM 仍是所有调试入口。倍速位于游戏战斗视口左下角，仅在游戏页面有远征时显示。

游戏页面左侧中央为主要战斗视口，房间战斗镜头依照可用高度适配并完整入镜。城堡、星图和星图编辑器都使用顶部栏下方整个 1392×784 内容区，隐藏游戏页的货币、交互、小队状态和药剂区域。

城堡页左侧可滚动列出配置中的全部城堡名称与攻略状态：未解锁、地牢完成数、等待攻略、计划攻击、已占领，状态颜色与世界地图一致。右侧显示完整世界地图；点击列表定位并勾勒统治区，点击地图同步选中对应城堡。列表选择不直接发起挑战，攻城仍从游戏交互卡安排。地图点击命中直接使用与绘制一致的原点及格宽。星图和编辑器保留原有购买、缩放、字段编辑、草稿保护与 GM 入口。

2026-10-18地图选择修订：左栏拆为上下独立区块。上方显示选中格的名称、编号、坐标、地形、所属城堡、攻略状态和本格地牢名称/等级/通关情况；地牢条目可独立滚动。下方保留全部城堡清单，高亮并滚动定位到选中格所属城堡。每次从其他页面切入城堡页默认选中玩家当前所在格，停留期间保留手动选择。点击地图或清单同时刷新详情和高亮，不发起挑战。右侧蓝色内框表示选中格，金色外轮廓表示选中格所属城堡的整个统治区域；青色仍表示玩家位置。两级边框错开绘制，即使选中格位于统治区域边缘也能分别辨认。

右侧上方只显示金币与杂物数量。杂物为实际背包库存，回城自动售卖为金币，悬停说明其用途；移除未投放的成长点占位及重复等级摘要。个人等级与经验仍显示在小队和英雄页。交互列表向上收拢，使用释放的空间，不新增资源类型。

右侧下方为滚动交互列表。功能排序约定为角色升级、穿戴装备、功能强化、挑战城堡，同类型按首次刷新时间排序；当前只投放第四类。每个满足门禁和普通地牢完成条件的未占领城堡拥有独立按钮，不受地图选择影响。按钮包含图标、名称、等级与描述；当前挑战免费，不显示消耗数量及资源图标。后续收费功能应同时显示消耗数量和资源类型图标。排队及执行中的卡片保留状态并禁用，通关占领后移除；刷新不改变仍存在卡片的先后顺序。按钮只调用 GameSession 命令。

左下角色区预留五个席位，每个已有角色显示占位图标、名称、等级、生命条、HP 和 ATK，空席显示占位。当前版本仍沿用三人开局，未扩展招募或阵容逻辑。右下药剂区仅展示四个占位槽，不生成可点击的强化或购买按钮。

开局选队放在右侧交互区，进入远征后隐藏。新增布局、占位图标、交互卡及刷新次序属于 UI 表现，不写入玩家成长数据。Godot 冒烟检查覆盖五区控件、三座城堡独立按钮、刷新顺序及点击排队；截图和检查只使用 artifacts/qa 专用存档。

## 单人创角与英雄编队（2026-10-21）

未解锁的英雄席位置灰禁用，保留“前往星图扩编”文案及悬停说明；点击不弹出专门确认窗口。已解锁空席仍可打开编队编辑，解锁及装配校验继续由GameSession执行。

顶部五个队伍槽位与右侧“调整编队”按钮共用一行；空槽整块可点击，打开编队并定位对应席位。槽位按钮保持实例，仅刷新文字和状态，避免战斗中HP/经验刷新在鼠标按下和松开之间销毁按钮而丢失点击。英雄技能区域不再摆放调整编队入口。

重置后只能选择一名初始可用英雄，角色围绕篝火摆放，点击角色或名字单选，开始游戏位于场景区内。顶部新增英雄全屏页：固定五槽、左侧成长及属性、右侧技能/装备页签（暂留空内容）。每名英雄显示个人等级、升级经验和生命；技能页提供三系天赋及主动技能装配。

初始职业为野蛮人、法师、游侠；圣骑士、死灵法师按配置累计击杀条件开放。英雄解锁条件目前在本轮进度内判定，重置进度同时重置累计击杀；没有独立账号系统。旧职业稳定 ID warrior/ranger/mage/priest 保留，priest 对应圣骑士，新增 necromancer。现有属性为原型值，职业专属技能后续配置。

新档一席，星图四个扩编节点各增加一席，最多五人，逐级手动购买。费用暂定25/50/75/100金币；圣骑士100击杀、死灵法师250击杀均为原型值。旧三人档保留原有队伍。英雄页点击已解锁空槽列出候选和锁定条件，上阵需在城镇无传送阶段执行，避免改变战斗/救援/进房检查点。已上阵职业不得重复加入；新英雄同步全队等级及星图加成。

## 编队弹窗与计划执行（2026-10-21）

编队弹窗使用设计尺寸944×560，居中遮罩。左侧五个席位显示当前草稿、已解锁空缺、未解锁三种状态；右侧英雄网格区分已上阵、草稿保留/待上阵、已解锁待命、未解锁及击杀门槛。先点席位再点英雄，可替换、移出、调整顺序；至少保留一名英雄且职业唯一。英雄页空槽与底部小队栏空槽加号共用弹窗，满编可从英雄页“调整编队”进入。锁定席位不显示加号，点击提示前往星图扩编。英雄页右下方旧候选列表及编队提示已移除，技能/装备区延伸至页面底部。

确认只创建编队计划，当前作战阵容保持不变；成功后直接关闭编队编辑，不弹“编队计划已加入”提示。右侧“计划列表 / 远征交互”显示计划与执行提示，可点击再次调整，也可在编辑弹窗撤销。一次保留一条待执行编队计划，再次确认更新该计划，避免执行过时阵容。取消编辑弹窗只丢弃当前编辑，不撤销已确认计划。

地牢内待当前房间清理、救援、拾取及事件完成后，打开回城门，集合进入并表演抵达，走近凯恩完成编队读条才更换成员。最后一层已全部清空时先正常记通关后返城；其他中途返城不记地牢通关、不发通关奖励、不记失败。已批准且中断的城堡回到队首；既有城堡/支线计划继续保留。室外赶路时改道回城，已经在城镇则直接前往凯恩；已有传送表演先完成，不强行打断。

变更后按既有流程完成治疗、售卖再继续自动远征。退下英雄进入候补，保留成长、技能及持有状态，共享后续等级成长与星图贡献，不重复领取奖励。

2026-10-21界面修订：每次启动默认进入游戏页；页签顺序为游戏、英雄、星图、地图（原城堡页）。创角占满顶部栏下方1392×784内容区，隐藏小队状态、药剂和右侧栏，模型与点击区共用布局偏移。

英雄技能页三系并排、每系最多三列并独立纵向滚动；下方主动技能栏与游戏小队栏血条右侧共用转圈冷却显示及装配弹窗入口。槽位由星图全队解锁，各英雄独立装配。详见[talent_trees.md](talent_trees.md)。

## 技能与编队交互优化（2026-10-21）
首次学会主动技能自动填入空槽；技能编辑点击优先填空，满槽先选择替换位置，拖动已有技能可交换。节点/列表共用拖动说明和悬浮说明，空白处可拖动滚动浏览。英雄编队候选点击同样优先填空，已有英雄拖到席位交换，满队需显式选席或拖放才替换；不可移出最后一名英雄，未变化的计划不提交。所有编队动作仍只改草稿，确认后由原有回城/凯恩流程执行。

2026-10-21职业内容覆盖：五职业都有三系原型节点，“游侠”显示名统一为“游侠”；每名新角色以1级获得的1点自动学习/装配配置的初始攻击，初始剩余0点。洗点可清除并返还，重开不补回。职业稳定ID和原解锁条件不变。

## 2026-10-26 V1.6语义补修

Lmax卡展示每名上阵英雄须分别满足的AR/DR阈值，评级分段仅为[H]原型提示；不以旧Armor表示DR。Lmin退休保持禁用并同时说明当前最低级和退休后最低级。五格卷轴使用既有作用方首名存活英雄选择最近合法敌人，平距按当前房间怪物索引稳定选择；无合法目标或无库存禁用。合批装备预览按队伍/配置部位稳定显示五项明确升级，不跨ATK/HP排名；一次操作仍穿全部可替换项。验证与开放项见[P2-4主review](../reviews/2026-10-25_p2_4_first_batch.md)第18节。
