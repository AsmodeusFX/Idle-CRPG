# 战斗公式：DMG1 / DMG2 / DMG3

2026-10-22执行更新。用户批准公式修改，并明确采用原型K(L)=5+(L−1)、元素抗性−100%～75%、取消最低1点保底、威能及易伤同池加算。以下为已实现规则；这些数值可通过CSV调整，不代表最终平衡。原始提案见[公式提案](combat_formula_vnext_proposal.md)，旧配置与历史公式输入归档于tests/fixtures/legacy_skill_bd_2026_10_22。

## 唯一执行入口与顺序

Skill/Effect → GameSession.SettleDamage → DamagePipeline.Resolve → GM/无敌/护盾 → 一次实际HP应用 → 唯一击杀经验及待拾取实物 → 后置效果队列。

DMG1解析攻击与分量，DMG2依次确定闪避/格挡/暴击，DMG3按分量防御和4+1结算后求和。混合分量共享一次事件事实；不会因分量多而额外掷随机数、扣血或发奖。命中不等于正扣血，正扣血不等于死亡。闪避短路，格挡与暴击可以同时成立；概率0/1不消耗随机数。

## DMG1与分量

有效攻击A，基础技能系数s，类型分量权重w_t：B_t=A×w_t。权重非负且合计1，同实例每类型至多一份。普通单类型w=1。

不再先计算Attack−Armor，也不保底1点。攻击、系数为0或完全格挡可以得到0。保留浮点，在各分量结算后求和；不分段取整。

Effect的damage_parts可填Physical:0.6;Fire:0.4，首项与damage_type一致；空值表示原单类型。份额share仍是整个Effect本体系数，不把混合分量拆成多次伤害实例。

## DMG2与4+1

| 因子 | 公式 |
|---|---|
| 技能S_t | s+Σ合资格技能系数加值；300%+30%=330% |
| 通用G_t | 1+Σ合资格通用增伤；火、远程、Boss等同池加算 |
| 威能P_t | 1+Σ合资格威能额外比例；+50%填0.5 |
| 易伤V_t | 1+Σ目标当前有效的合资格易伤贡献；不同Debuff ID也加算 |
| 暴击C_t | 暴击时base_critical+额外暴伤+合资格暴击加值，否则1 |

暴击默认原型1.5。增伤按技能ID、类型、远程、Boss、Debuff等过滤，再聚合；不新增光环、召唤、Proc或队伍乘区。易伤贡献仍必须有有效稳定DebuffId；同效果先由Buff重复策略确定有效实例，再参与伤害。

旧DamageBucket数值3现在是Power，存储额外比例；旧独立倍率x1.5转换为+0.5。旧x1.5与x2相乘3现在为1+0.5+1=2.5，这是已批准的公式变化，不能宣称结果等价。旧条件斩杀/目标已有状态转换为条件威能；分身强度与DoT单跳比例缩放技能本体，不错误混入威能池。

## 防御与总式

物理：F_phys=K(L_attacker)/(Armor+K(L_attacker))。Armor非负，K为正。combat/armor_curve.csv按控制点线性插值，当前1级K=5、10000级K=10004，即K(L)=L+4。只使用攻击者出手等级，不使用目标等级。

元素：R_t=clamp(基础抗性+抗性增益−减抗,−1,0.75)，F_t=1−R_t。火/冰/雷/毒各自独立；元素不再重复受护甲减伤。抗性贡献先合并，只在防御解析时截断一次。负抗可增伤，上限75%不形成完全免疫；不额外添加减抗乘区。

格挡Q成功时为1−block_reduction，否则1，同一实例共用格挡事实。

D_formula=Σ_t[B_t×S_t×G_t×P_t×V_t×C_t×F_t×Q]。

DamageBreakdown.Components保留每类型的权重、各池、防御及伤害；顶层池字段供单类型/首分量诊断，混合总伤害只看FinalDamage。输入、分量、结果必须有限，拒绝非法权重、负基础、越界等级、非正K或溢出。

## 快照、存档与奖励

SkillAttackSnapshot保存Attack、Level和进攻属性；在途升级不回写旧攻击等级。目标防御、抗性、闪避/格挡和有效易伤在命中时读取。现有15技能的暴击/DoT资格继续保留：同一发首个有效命中确定暴击，派生DoT继承该事实，不把所有周期变成直接武器命中。

CombatVersion=2。旧0版按模板补战斗元数据；旧1版威能倍率减1且只迁移一次，旧在途缺少出手等级时采用该旧快照攻方等级。正式CaptureProgress仍清空SkillState并重开房间，不保存怪物战斗现场；成长、资源、装配与换入等待按既有合同保留。

GM怪物攻击倍率在基础解析前应用，有效怪物血量倍率在公式后应用。护盾只吸收合计伤害一次；死亡目标拒绝再结算。经验即得，金币/杂物仍是清房救援后走近拾取；失败重开允许再次获得击杀经验的规则不变。
