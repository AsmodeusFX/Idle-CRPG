# 固定城镇、自动攻略与传送

2026-10-19用户确认。本文覆盖此前手动授权整条支线、最终房间走出口回地面、连续世界行商补给的旧规则。

## 固定城镇

城镇是独立局部场景，不再用世界格子上的单个行商代替。罗格营地按用户参考图的相对分区布置围栏、唯一东侧门、桥梁、道路、溪流、树木及帐篷/货车/锻炉。六位NPC：北侧恰西、东侧阿卡拉、西侧基德、西南卡夏、中央凯恩、出口附近瓦瑞夫。为程序绘制的原型场景，未使用D2原始美术资源，不宣称像素级复刻。

阿卡拉仅实现免费治疗；恰西仅实现杂物售卖。其他售卖、装备、修理、雇佣兵、赌博、鉴定、瓦瑞夫的手动跨幕功能均未开放。小队必须实际走到交互距离内，依次执行治疗→售卖→前往出口或固定传送阵。治疗结束才满血；售卖结束才到账并清理背包。阶段变化保存，读档不重复售卖。全灭仍按已有明确例外直接满血复活，再完成城镇流程。

普通出入走唯一门，城镇传送是明确例外。所有移动和建筑绘制共用局部坐标，建筑与围栏阻挡寻路。世界坐标停留在主城锚点，局部场景坐标不写成世界格子坐标。出生及跨章到达从营地入口内侧出发。章节2～5接入各自固定场景ID和相同六种服务角色；当前共用原型布局，待正式规划，不擅自更改世界地图结构。

## 两处城镇传送设施

中心回城门：玩家从地牢就地施放的回城门在城镇的落点。首次来到该难度/章节时不显示；从任一地牢/要塞传回后常驻。显示状态按地图进度保存，回旧章仍保留，不因去下一章消失。新难度独立。

固定传送阵：位于用户标记2的中东部位置，是从城镇前往区域传送点的设施。固定底座一直可见；使用时临时展开门、队伍进入、目的地展开抵达效果；临时门使用后消失，底座保留。不会从中心回城门出发。

## 区域传送点

一个统治区域一处，落在有地牢的可进入格。首版用固定种子离线挑选地块，结果写入CSV，运行与读档不重新随机。实际落点与本格所有地牢/要塞入口至少相距0.18个世界格，绘制不额外偏移，保证看见的位置等于真实落点。

该地块全部地牢（含要塞）通关后解锁。区域门禁仍须满足，普通难度的点不能用于噩梦，旧章节的点不能用于当前章节。出城时在当前执行地图内已解锁且到目标可达的点中比较实际导航路径长度，取最近点（同距稳定ID排序），传送后沿正常道路走向目标。尚无可用点则走唯一城门。不凭传送绕过any/all区域门禁或要塞授权。

普通地牢/要塞最终层清空，完成救援、拾取及事件后，小队在当前位置主动打开回城门，进入并传到中心。最终Boss房不绘制/要求返回地面的出口，不再先走楼梯集合；中间楼层仍走楼梯集合换层。回城门依次经历打开、进入、目标地点抵达三个逻辑阶段，动画只读逻辑，不在绘制中移动或发奖励。GM瞬间通关仍为明确的跳过战斗例外。

## 最新攻略与支线

当前执行难度/章节所有已解锁、可达、未通关的普通地牢一起选，包含主线和支线。优先最低挑战等级，同等级随机；随机状态随档保存。auto_order不再打破同级随机。待攻略主支线要塞均需玩家批准，不进入自动候选。

支线普通地牢解锁后自动探索，无需整条支线授权。当前章节清完支线普通地牢后，显示普通的“挑战要塞”卡；进入后续章节仍显示可返回挑战的旧章支线要塞卡。旧章挑战在正常补给边界切回对应主城，完成后补给并返回最新章节。支线要塞未完成不影响主线完成或跨章。旧存档若留有未探索的支线普通地牢，点击旧章卡授权返回后，先按最低挑战等级补扫这些地牢，再执行该次已批准的要塞挑战；不会绕过要塞资格。

## 2026-10-19：按需补给与跳过补给

城镇移动、服务读条及传送共用全局 1/2/4 倍速固定时钟；移动消耗完整距离预算，不在半格路径点丢失剩余移动距离。

2026-10-22 步行速度：城镇镜头按场景尺寸固定缩放，五章尺寸差异大，统一`village_speed`会让大场景的屏幕移动明显偏慢。town_scene新增`walk_speed`按章配速（第一章12.49、第二章21.13、第三/五章14.41、第四章10.57，原型值），使各章屏幕步速都约为220像素/秒：典型地牢房间`hw+hh≈7`时缩放约58，英雄平均速度3.78，约220像素/秒。该值只用于城镇场景内的移动与走向固定出发阵；旧村庄与地牢回城门仍用`village_speed`。这是镜头缩放的配速补偿，不是用降速掩盖渲染压力，静态背景缓存与视口裁切保持不变。

全队 HP 满且无负面效果时跳过治疗；否则走近治疗 NPC 后恢复 HP、清除负面效果。MP 当前尚未实现，接入后必须纳入满值判断和恢复。背包没有 AutoSell 配置物品时跳过铁匠；有则走近售卖后到账。装备尚未投放，当前以现有物品配置为准。服务保持治疗→售卖顺序和原有阶段保存边界。

GM 关卡测试增加“跳过补给”，默认关，读档或重置调试关闭。开启后回城直接进入出发阶段，不治疗、不清除效果、不出售物品；仍走近固定传送阵，无可用点时走唯一城门。可在补给途中生效，目标选择和要塞授权不变。

未来增加 NPC 或 NPC 功能时，必须复核补给需求、服务顺序、跳过条件及保存边界。
