# 随机地牢与战斗 · 首版

## 已明确的需求

地牢由房间和走廊组成。进入地牢前按 seed 生成所有层的房间总数、几何结构和连接；不生成房间怪物和事件。任意队员首次接触通向新区域的门，才揭示该区域并按当前独立刷怪配置、科技加成预留参数和地牢等级区间生成内容，同时启动双方索敌。走廊不生成怪物。已探索区域在本轮地牢中永久可见。

小队开局选定后成员不变。AI 清空本层所有房间才进入下一层。最远端房间为楼梯/BOSS 房间，BOSS 与普通怪一样在首次进入时生成；所有楼层怪物清空即通关。

当前房间清空后，如果存在阵亡队友，存活队员先前往队友倒地位置，自动交互等待 n 秒后完成复活；所有队友获救后才继续探索。全队阵亡则直接在当前区域村庄满血复活，放弃本轮地牢，已积累的等级、经验、金币及拾取资源和世界通关进度保留。完成村庄交易补给后，按正常目标选择规则继续冒险；再次进入地牢时重新生成结构，房间内容仍在首次触门时生成。

## 首版暂定规则（可调整，非最终策划）

- 从战士、游侠、法师、祭司中选择 3 人；所有职业先使用不同射程的普通攻击，技能后续扩展。
- 每层生成无环连通树，房间在网格内随机扩展；两房间之间为独立走廊。起点安全，无怪物。
- 房间长宽也在结构阶段随机，默认宽 6–9、高 5–8；门、走廊、怪物出生和战斗边界共用真实尺寸。镜头入房后按完整房间锁定，赶路跟随排头，详见 camera_world_view.md。
- 分别使用结构随机源、房间内容随机源和掉落随机源；相同 seed 重现结构。内容取决于首次进入时的独立刷怪参数，不再跟随英雄等级或楼层自动提升。
- 首次进入时对怪物等级、数量和事件做快照；已生成内容不随成长追涨，回访不刷新。门触发揭示后本房间双方开始索敌。
- 门触发距离为 0.32 世界单位。先穿过房门进入走廊，再穿过另一端门进入目标房间。显示已探索走廊不会泄露相邻房间。
- 全队选择最近未清理房间，按图寻路。战斗时攻击最近活敌，距离相同时用稳定列表顺序。死亡队员不行动。
- 伤害 = max(1, 攻击 - 防御)，冷却按秒计时。击杀立即发放共享经验；每达到等级 × 18 经验全队升级，增加 HP 和攻击，存活成员恢复升级增加的 HP。
- 普通房间概率生成营火或宝箱；击杀清空后自动交互，营火恢复存活队员 30% 最大 HP，宝箱获得 8 经验。事件每轮只结算一次。怪物可掉金币与杂物；拾取自动结算，通关回村售卖杂物。
- 全层清空且完成救援后全队走到楼梯集合，自动下一层；每层状态保留。最后一层清空且完成救援后通关。
- 救援暂定：一位存活队员就近前往倒地队友处，进入 0.65 世界单位交互范围后等待 3 秒，恢复目标 50% 最大生命。多个死者依队伍顺序逐个救援；多人不加速，其他队员等待。离开范围重新计时；有活怪时不救援。救援先于事件结算、换房、换层和通关。时间、范围、复活生命比例均为 CSV 配置。
- 全灭后全队在当前区域村庄满血恢复，攻击冷却、救援读条、交易读条及寻路状态清零；等级、属性、经验、累计击杀、金币和背包保留，世界通关进度不变，失败地牢不计通关。必须走到交易 NPC 处并完成交互后再出发，杂物按正常售价结算，不收取复活费用。
- 可暂停、1/2/4 倍速，首次开局选择 seed。进度自动保存，重新打开自动继续；重置进度需在设置中二次确认。当前无离线结算、装备和主动技能。

## 验收

进场只显示安全起点；首次门触发才生成下一房间；走廊始终无怪；同一轮回访无重复内容；刷怪加成只影响后续房间快照；图连通；BOSS 在最远房间；尚有存活怪时不能换层；固定队员贯穿整次挑战。清房后走到尸体处等待完整读条才复活，全部救援前不换房/换层；全灭在当前区域村庄复活，保留成长和资源，完成村庄流程后继续冒险。
