# 随机地牢与战斗 · 首版

## 已明确的需求

地牢由房间和走廊组成。开局先按 seed 生成所有层的房间总数、几何结构和连接；不生成房间怪物和事件。任意队员首次接触通向新区域的门，才揭示该区域并按当时队伍等级、地牢难度和楼层生成内容、同时启动双方索敌。走廊不生成怪物。已探索区域在本次地牢中永久可见。

小队开局选定后成员不变。AI 清空本层所有房间才进入下一层。最远端房间为楼梯/BOSS 房间，BOSS 与普通怪一样在首次进入时生成；所有楼层怪物清空即通关。

当前房间清空后，如果存在阵亡队友，存活队员先前往队友倒地位置，自动交互等待 n 秒后完成复活；所有队友获救后才继续探索。全队阵亡则返回同一地牢的一层入口，所有层的房间内容、怪物、事件和探索状态刷新，已积累的等级、经验及拾取资源保留。重挑战不改变队伍成员与地牢拓扑；房间仍在首次触门时按保留后的成长重新生成内容。

## 首版暂定规则（可调整，非最终策划）

- 从战士、游侠、法师、祭司中选择 3 人；所有职业先使用不同射程的普通攻击，技能后续扩展。
- 每层生成无环连通树，房间在网格内随机扩展；两房间之间为独立走廊。起点安全，无怪物。
- 分别使用结构随机源和房间内容随机源；相同 seed 重现结构。内容还取决于首次进入时的队伍平均等级。
- 首次进入时对怪物等级、数量和事件做快照；已生成内容不随成长追涨，回访不刷新。门触发揭示后本房间双方开始索敌。
- 门触发距离为 0.32 世界单位。先穿过房门进入走廊，再穿过另一端门进入目标房间。显示已探索走廊不会泄露相邻房间。
- 全队选择最近未清理房间，按图寻路。战斗时攻击最近活敌，距离相同时用稳定列表顺序。死亡队员不行动。
- 伤害 = max(1, 攻击 - 防御)，冷却按秒计时。击杀立即发放共享经验；每达到等级 × 18 经验全队升级，增加 HP 和攻击，存活成员恢复升级增加的 HP。
- 普通房间概率生成营火或宝箱；击杀清空后自动交互，营火恢复存活队员 30% 最大 HP，宝箱获得 8 经验。事件只结算一次。
- 全层清空且完成救援后全队走到楼梯集合，自动下一层；每层状态保留。最后一层清空且完成救援后通关。
- 救援暂定：一位存活队员就近前往倒地队友处，进入 0.65 世界单位交互范围后等待 3 秒，恢复目标 50% 最大生命。多个死者依队伍顺序逐个救援；多人不加速，其他队员等待。离开范围重新计时；有活怪时不救援。救援先于事件结算、换房、换层和通关。时间、范围、复活生命比例均为 CSV 配置。
- 全灭后全队在一层入口满血恢复，攻击冷却、救援读条及寻路状态清零；等级、属性、经验和累计击杀保留。当前版本未实现拾取背包，后续加入的拾取资源也必须保留。清空各层内容后按原 seed 结构重新挑战，已结算奖励不回收，新一轮房间可重新结算。
- 可暂停、1/2/4 倍速、输入 seed 重开。首版无离线结算、持久化存档、装备和主动技能。

## 验收

进场只显示安全起点；首次门触发才生成下一房间；走廊始终无怪；同一轮回访无重复内容；成长影响后续房间快照；图连通；BOSS 在最远房间；尚有存活怪时不能换层；固定队员贯穿整次挑战。清房后走到尸体处等待完整读条才复活，全部救援前不换房/换层；全灭回到一层，重置各层内容与探索，保留成长和资源。
