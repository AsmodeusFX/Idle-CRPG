# 世界、自动远征与物品

## 已确认规则

世界为 CSV 配置的 16×16 矩形区域网格。每区一个村庄、若干普通地牢，部分区域另有一座城堡。每区通过显式关联恰好受一座城堡统治。小队在区域 1 初始村庄出生，固定队员，全自动出发挑战最低等级普通地牢。世界不刷怪。

普通地牢或城堡通关后，必须先回该区域村庄，步行到交易 NPC 处自动交互，卖掉全部杂物、免费补给满血，再选择下一目标。金币没有消耗口；怪物概率掉杂物、直接掉金币；物品类型与单价、掉落概率与数量单独配表。全灭直接刷新到当前区域村庄满血复活，放弃本轮地牢，累计资源、世界进度与队员保留，完成同样的交易补给流程后继续冒险。

城堡解锁要求其统治范围内所有区域的全部普通地牢通关。城堡通关即占领其全部统治区域。四种地图状态优先级：已占领（绿）> 整个统治区全部普通地牢通关、等候玩家挑战城堡（整个统治区橙色）> 已展开扫荡（灰）> 未展开（地图底色）。单一区域清空不变橙。城堡图标始终显示；标记小队所在区域。经过区域会展开该区域。

刷怪模块独立：数量上下限初始为 1–5，等级基础为 1。取消随英雄等级和楼层自动涨怪，临时地牢等级区间另配；首次进房时对数量、等级与掉落加成快照。预留数量下限增量、上限增量、怪物等级增量、掉率和价值倍率；不实现科技树界面或加点。怪物等级提升会同步提升属性、经验、金币数量和杂物售价。

## 首版实施细节（暂定）

- 世界、区域、统治关系和地牢实例为固定 CSV，内部房间结构仍按 seed 随机；每次进入地牢重新生成内部结构。全灭放弃旧地牢，复活点是当前区域村庄，不是初始村庄或地牢入口。
- 先完成当前区域剩余普通地牢（等级升序），随后选择相邻未完成区域。城堡由右侧“挑战xx城堡”按钮主动安排，地牢/返村/交易中点击则排队，交易完成后优先出发；没有点击时继续自动冒险。移动使用统一世界坐标的细网格 A*，可沿已探索区域回溯并绕过岩石、水面。
- 当接壤区域全为橙色且无新的相邻目标，先复刷橙色区域中最高等级普通地牢，下一次允许回溯到尚未完成的探索边界。无橙区时继续寻找边界；全部普通地牢完成但尚未点击城堡时继续复刷，不停止挂机。
- 交易耗时 2 秒，无购买；初始村庄首次出发不等待交易。物品自动拾取，无背包容量限制。
- 地牢配置等级区间 + 刷怪基础等级 − 1 + 未来科技等级增量 = 实际怪物等级区间。当前不额外随楼层、英雄等级变化。BOSS 占房间刷怪总数中的一个名额。
- 物品按“物品 ID + 单件售价”堆叠；掉落时锁定售价，后续升级不追溯改价。金币数量、杂物售价乘 1 + (怪物等级−1)×价值成长。经验 = 配置基础经验×怪物等级，BOSS 再乘奖励倍率。
- 连续世界场景按北雪、南热带、西沙漠、东水域区分地貌；道路、植被与地形是程序绘制的占位美术。默认只跟随角色，不自动打开世界进度地图；进度地图由玩家主动查看。详见 camera_world_view.md。

## 配表原则

region 不重复写地牢数量，数量从 dungeon 实例表统计。village 独立逐区配置，castle_region 独立关联；校验完整矩形坐标、ID 唯一性、引用、村庄数量、地牢等级、城堡归属及统治覆盖。不会因缺字段静默生成世界数据。
