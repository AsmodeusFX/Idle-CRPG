## 已批准方向与待定边界

物理递减护甲 `DR=Armor/(Armor+K(L))`，L取攻击者等级；四元素各用自身有效抗性，允许负抗；四常规增伤池内加算、池间相乘，加独立暴击因子。不增加第六伤害类型，不把减抗再计入增伤池。

下述混合分量、命中事实共享、基础保底、威能输入与条件效果归属是落实这些方向的具体建议，批准前不进入正式默认或悄悄替换旧算法。

## 1. 唯一实例和阶段顺序（建议）

一次DamageInstance对一个目标，可含若干伤害类型分量。DMG1解析有效攻击、来源/资格、技能系数、攻击者等级和分量权重；DMG2前置依次决定闪避/格挡/暴击；DMG3逐分量解析防御及4+1后求和；随后无敌/GM/护盾、一次原子HP应用和唯一死亡/奖励；最后发后置事实排队。

同一实例只掷一次命中相关事实并共享至各分量，不把“物理+火”拆成两个独立暴击/死亡事件。不同合法Hit仍各有实例。命中失败则整次0伤害；被盾全吸收不撤销命中事实，但不产生正扣血事实。

## 2. DMG1：分量与技能基础（建议）

令有效攻击为A，技能基础系数为s，某类型分量权重为w_t。权重非负且总和为1；纯单类型w=1。`B_t=A×w_t`，`S_t=s+Σ符合本分量资格的技能系数加值`。

300%技能加30%仍是S=3.3。权重先拆基础，再乘本分量适用系数/增益；不把系数加值对每分量重复当作额外一份完整基础伤害。混合比例由技能配置给出，尸爆是否由尸体生命提供基础另行设计，不强行用英雄攻击替代。

建议新公式取消旧“攻击减护甲后的最低1点”中间保底，A或系数为0时允许0，最终不强制保底。若保留最低伤害，必须单独规定作用于实例还是分量，避免分量越多保底越高。此项尚待批准。

## 3. DMG2与防御（建议中的细化）

闪避→格挡→暴击顺序及格挡/暴击可共存沿用现行合同。`C=base_critical+额外暴伤+Σ合资格暴击加值`，不暴击为1。建议保持现有原型基础暴击1.5；概率/具体技能资格仍按配置，不因新公式自动开放DoT或Proc资格。

物理：`F_physical=1-Armor/(Armor+K(L_attacker))=K(L_attacker)/(Armor+K(L_attacker))`，Armor非负，K必须有限且大于0。仅物理分量受护甲；元素分量不再重复减护甲。

元素t：`R_t=clamp(R_base,t+Σ抗性增益_t-Σ减抗_t, R_min,t, R_max,t)`，`F_t=1-R_t`。抗性使用比例，25%=0.25。信念与降低抵抗在同一次有效抗性聚合中合并后只截断一次。负抗可使F>1；上限必须小于1以满足无完全免疫方向。

成功格挡时`Q=1-block_reduction`，否则1；建议继续对该实例各合法分量应用同一Q。格挡是防御因子，不新增进攻池。若未来某类型/技能不可格挡，须单项声明。

## 4. 四常规池和总式（建议中的细化）

| 项 | 建议公式 | 输入语义 |
|---|---|---|
| 技能 | `S_t=s+Σskill_bonus_t` | 系数3.0，加值0.3 |
| 通用 | `G_t=1+Σgeneral_bonus_t` | 物理、火、远程、Boss等按资格同池加算 |
| 威能 | `P_t=1+Σpower_bonus_t` | 统一存额外比例；+50%填0.5，不填1.5 |
| 易伤 | `V_t=1+Σ有效易伤贡献_t` | 不同诅咒的合法同类贡献也加算；先按Buff策略筛出有效来源，禁止重复消费 |
| 暴击 | `C` | 独立事件因子，沿用上述事实 |

`D_formula=Σ_t[B_t×S_t×G_t×P_t×V_t×C×F_t×Q]`。

最终采用浮点，一次求和后进入HP/护盾应用；不对每分量或每个乘区取整。不新增光环/召唤/Proc/队伍倍率。所有输入和输出必须有限，拒绝负基础、非法权重、非正K和溢出。

**旧数据迁移建议：**旧x1.5独立倍率对应新power_bonus=0.5；两条旧x1.5与x2原相乘为3，新池加算为2.5，这本身会改变伤害，不能声称等价转换。斩杀/已有状态的旧条件倍率必须逐项归属；建议若保留其增伤语义则作为有条件威能贡献，不再叠乘旁路。旧物理易伤与元素易伤须声明类型资格，不能通用扩大收益。旧样例保持测试归档用于对照，不修改历史算例伪装成新基线。

## 5. 快照、HP与事件（建议）

攻击者等级、有效攻击、进攻贡献、技能/来源及分量规格随伤害原因保存；目标防御、当前抗性/减抗、闪避/格挡、有效易伤和条件生命比例在命中时解析。弹道飞行中升级不回写旧攻击等级。DoT继续/改变快照与暴击的策略逐技能声明，旧15技能现行语义先保留为回归合同。

GM怪物攻击倍率在基础攻击解析时进入；玩家打怪的有效血量倍率在公式后应用；无敌、护盾、实际扣血、经验、待拾取实物顺序沿现有唯一入口。正扣血/击杀事实依据实际HP变化，不依据D_formula大于0直接推断。

## 6. 手算样例（仅验证公式，不是生产平衡值）

设A=100，物理/火权重0.6/0.4，S=1；G=1.3；P=1.5；物理易伤V=1.2，火易伤V=1.1；本次暴击C=1.5，格挡Q=0.5。目标Armor=100，本次攻击者等级对应K=100，火基础抗性50%、信念减20个百分点、降低抵抗减10个百分点，因此有效火抗20%。

- 物理：`60×1×1.3×1.5×1.2×1.5×0.5×0.5=52.65`。
- 火：`40×1×1.3×1.5×1.1×1.5×0.8×0.5=51.48`。
- 一次实例总公式伤害104.13，随后统一处理护盾/HP，不能产生两次死亡奖励。
- 若有效火抗为-20%，火防御因子变1.2；纯100基础火伤且其他因子为1时得到120伤害。
- 两个合资格易伤20%/30%合计V=1.5，不再是1.56；相同效果来源先按Buff叠加策略过滤。
