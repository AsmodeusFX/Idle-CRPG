# GM 调试与编辑器菜单

只读参考 E:/Git/Idle-Sword/idle-sword/UI/GmPanel.cs 与 UiKit.cs 的靛青面板、暖金标题、青玉分区标题和上下两区格局，不修改参考工程。入口仍位于设置旁。打开 GM 暂停模拟，关闭后沿用玩家原有暂停状态。

上半区为当局指令。当前提供金币、共享经验发放、全队无敌、怪物有效血量倍率、怪物攻击倍率、每房额外怪物数量，以及重置战斗调试。所有状态变化都通过 GameSession 命令；未开始远征时禁用这些按钮。资源发放数、倍率档位和数量步长由 gm/gm.csv 读取并校验，均为原型调试参数。

无敌只阻止怪物对存活队员造成伤害，不复活已倒地队员。攻击倍率在正常伤害公式扣防前乘入怪物攻击。有效血量倍率通过正常伤害除以倍率实现等效生命：改变倍率时生命百分比不跳变，不修改怪物出生模板、等级、经验或掉落。两种倍率立刻影响当前及后续战斗；默认 1 时与原有伤害一致，伤害仍只有 GameSession 一份实现。

每房额外数量加在原配置的正常随机数量之后，最终限制为 1–1000，BOSS 仍占总数中的一个名额。调整只影响后续首次进入、首次生成的房间；已生成房间不增删怪物，不重新发放奖励。全队无敌、两种倍率和数量加值是临时会话参数，重新开局或读档恢复默认，不写入正式进度快照，也不修改 CSV。已经生成房间的数量仍按正常出生快照保存，读档重开房间时保留该数量。

金币及共享经验是真正到账的进度，经验升级复用正常公式，不另设 GM 成长实现；资源与成长触发正常关键状态保存。重置战斗调试只关闭无敌并恢复倍率 1、额外数量 0，不回滚已发放资源或已生成房间。

下半区为编辑器入口。目前星图节点编辑器可用，进入时先关闭 GM，再打开全屏编辑器；开局前也允许使用。关卡编辑器当前禁用占位。星图草稿保护、外部冲突检测和已购节点兼容校验继续使用现有实现。

核心检查覆盖资源与成长、溢出拒绝、无敌开关、即时倍率、后续刷怪数量、正式检查点重开、临时参数不恢复和 CSV 非法值拒绝。Godot 冒烟检查点击真实 GM 按钮并验证上下分区。`--capture --capture-gm` 可生成窗口预览，检查和截图只使用 artifacts/qa 专用存档。
