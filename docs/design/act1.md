# 第一章：地图、攻略与失败回刷

2026-10-18实施版本。以用户确认覆盖AI参考文档；原始资料及哈希见 [来源归档](../references/act1/2026-10-18/manifest.md)。字段见 [第一章配置](../technical/act1_config.md)，验证见 [验收记录](../reviews/2026-10-18/act1_implementation_audit.md)。

## 地图与主线

第一章使用8×8完整网格：64格，15个阻断格、48个统治区域格、1个独立营地格。8个统治区域、33个普通地牢、8个要塞，共41个POI。坐标对外为一基；罗格营地在(x4,y5)，内部零基(3,4)、region_id=36。每次普通地牢或要塞结束，包括全灭，先回这个村庄交易补给再选目标；营地不属于任何统治要塞，不参与通关计数。

同一区域内部连续移动；跨区域只能经过配置的8对关口，且目标区域必须已解锁。地牢入口和关口是不同概念。阻断格只勾勒地形，不可通行、不放地牢。区域门禁按配置的any/all计算，见 [门禁规则](map_access.md)。

主线包含37个POI，埋骨之地所在第三区4个POI为支线。A08-C01（大教堂及地下墓穴）真实通关为第一章主线完成条件；仍须正常回营地交易，之后进入第二章，支线可未完成。后续章节2～5保持已有地图结构，等待正式规划。三难度各自保存第一章进度，普通记录不能用于噩梦门禁。

## 自动攻略与玩家授权

2026-10-19最新规则：普通地牢在当前执行地图内选择已解锁、可达、非blocked内容，主支线一起按最低挑战等级优先，同级随机；auto_order不再打破同级随机。推荐等级仅提示。所有要塞仍手动批准，没有开拓目标时继续复刷。

埋骨之地普通地牢现在解锁后自动攻略，无需支线按钮；支线要塞仍需批准且不阻断主线及跨章。旧章未通关支线要塞满足资格后可通过独立卡返回挑战，结束后返回最新章。固定营地及两处传送设施规则见 [城镇与传送](towns_portals.md)，覆盖此前整条支线手动授权规则。

Boss目前为明确标记的可战斗原型，真实清空并完成救援、拾取及事件后，小队就地开回城门，不再设置最终层地面出口。中间层仍走楼梯。安达利尔只在A08-C01末层生成；专属机制尚未实现。

## 高等级失败后的回刷

小队挑战等级暂取上阵成员最低等级。仅目标挑战等级高于小队时，失败计入该目标计数；默认阈值2，来自world/recovery.csv。低于阈值的已授权要塞保留本次挑战授权；达到阈值后暂停该目标，先返村交易，再选择当前执行难度/章节内已通关、可达的普通地牢：最高挑战等级≤小队等级；同级随机；没有符合等级的已通关目标时，退到最低等级已通关普通地牢。

小队挑战等级变化后，失败普通地牢可自动重试。失败要塞仍须玩家点击带红字“（再次挑战）”的卡片，不能升级后自动发起；支线要塞也遵守失败后的重新授权。再次授权或成功通关会清除该目标失败记录。失败计数、暂停时等级、重试标记和随机状态随档保存。

边界：本地图尚无任何已通关普通地牢时，无法生成合法复刷目标，继续原普通地牢开拓规则，不虚构首通记录，也不跨章节借用复刷目标。

## V0.5数值的生效边界

V0.4提供拓扑、POI和关口；V0.5及data补充41个POI三难度等级（123行）、每难度69层（共207行）的楼层计划和预算。运行时已使用POI层数、挑战/推荐等级、逐层怪物等级、末层Boss标记和名称。普通/噩梦/地狱规划击杀目标合计2517/2601/3439，只是计划校验值，绝不直接发经验、掉落或通关。

LayoutRows/Cols、CellKind、Arena面积及密度仍为未经实测的规划数据。本轮保留原房间/走廊生成和怪物数量规则，没有把建议表直接替换成正式遭遇。FloorReports并列报告计划格数/击杀与实际房间、走廊、生成怪数、击杀事实及逻辑耗时，不宣称实际数量已达到预算。
